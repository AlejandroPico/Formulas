# Operadores de creación y destrucción

Actúa sobre un estado número del oscilador. Separa coeficiente de amplitud del nuevo estado normalizado; destruir el vacío produce el vector cero.

## Magnitudes y notación

| Símbolo | Interpretación |
| :-- | :-- |
| n | Número cuántico entero que identifica el nivel. |
| a | Operador de destrucción del oscilador. |
| † | Adjunto hermítico: intercambia crear y destruir. |
| ∣ | Inicio de un ket: vector de estado cuántico. |
| ⟩ | Cierre del ket que contiene la etiqueta del estado. |

## Condiciones

Estados número del oscilador bosónico, n entero no negativo. Los coeficientes de amplitud no son probabilidades de aplicar un dispositivo físico: la realización experimental del operador requiere un proceso adicional. El dibujo del estado final usa unidades reducidas.

## Unidades

a,a† y n adimensionales. La coordenada ξ=x√(mω/ħ) es adimensional, y la densidad mostrada es por intervalo dξ. El coeficiente √n es norma de un vector no normalizado.
