# Multiplicar un paso tras otro

Una progresión geométrica usa una razón constante r. Con a₁ = 2 y r = 3, los términos son 2, 6, 18… Sₙ suma los primeros n, y aₙ solo nombra uno.

La suma finita admite razones negativas, cero y uno. Si r = 1, todos los términos son a₁ y la suma es na₁; no dividas entre 1−r. Si r = 0, solo el primer término puede ser distinto de cero.

Para a₁ ≠ 0, las sumas infinitas convergen exactamente cuando |r| < 1. Una razón negativa alterna signos. Si a₁ = 0, la serie es cero para cualquier r: es el caso trivial.

**Cosecha** propone acumulados; **Explorar** compara términos y sumas; **Límite** muestra la distancia que falta hasta una suma infinita cuando existe.
