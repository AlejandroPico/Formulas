# Restar una copia desplazada

S = a₁ + a₁r + … + a₁rⁿ⁻¹. Multiplicar por r da rS = a₁r + … + a₁rⁿ.

Al restar, se cancelan los términos interiores: (1−r)S = a₁(1−rⁿ). Si r ≠ 1, divide entre 1−r. Si r = 1, suma directamente n términos iguales.

Para |r| < 1, rⁿ tiende a cero. El límite es a₁/(1−r). El resto tras n términos es Rₙ = a₁rⁿ/(1−r), cuyo signo puede alternar si r es negativo.

La demostración no exige r positivo. Una razón como −1/2 produce sumas parciales que se acercan al límite por lados alternos.

En Límite, la línea horizontal se dibuja solo cuando existe un límite; el gráfico no sugiere convergencia cuando r ≥ 1 o r ≤ −1 y a₁ ≠ 0.
