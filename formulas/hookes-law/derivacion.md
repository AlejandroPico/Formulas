# Derivación

Hooke es una ley constitutiva experimental: la linealidad se comprueba al medir fuerza y deformación en un rango. No se deduce solo de F = ma.

Si x aumenta a la derecha, el resorte busca x = 0, por eso Fres = −kx con k positivo. En equilibrio cuasiestático Fext+Fres = 0, así Fext = kx.

El trabajo externo desde cero hasta x es U = ∫₀ˣ kξ dξ = kx²/2. La fuerza restauradora es −dU/dx = −kx. Esta energía pertenece al modelo lineal: fuera del rango validado no se puede atribuir automáticamente a un resorte real.
