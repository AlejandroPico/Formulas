# Pozo de potencial infinito: partícula en una caja

Caja 1D con paredes infinitas. Mezcla estados n y n+1 para ver densidad dinámica; no dibuja un rebote clásico de la partícula.

## Magnitudes y notación

| Símbolo | Interpretación |
| :-- | :-- |
| ψ | Función de onda compleja normalizada; su módulo al cuadrado da densidad de probabilidad. |
| ħ | Constante de Planck reducida h/(2π). |
| i | Unidad imaginaria: i²=−1. |
| E | Energía del estado o autovalor especificado. |
| t | Tiempo físico o tiempo reducido según las unidades del laboratorio. |
| x | Coordenada espacial; en la caja pertenece al intervalo entre paredes. |
| m | Masa de la partícula. |
| n | Número cuántico entero que identifica el nivel. |
| φ | Fase relativa. |
| L | Anchura de la caja. |
| V | Potencial energético, cero dentro y prohibitivo fuera. |
| q | Peso del nivel n+1. |
| ϕ | Fase relativa. |
| sin | Seno de la autofunción confinada. |

## Condiciones

Paredes ideales infinitas y partícula no relativista. El tiempo de reproducción es reducido; no se interpreta la densidad como una bola rebotando. q=0 o q=1 recupera un estado estacionario y anula la interferencia temporal.

## Unidades

L/Lref y q adimensionales; energía en E1(Lref)=ħ²π²/(2mLref²). La fase relativa usa grados. Para la reproducción se emplean ħ=m=1 y tiempo ħ/Eref, no segundos arbitrarios.
