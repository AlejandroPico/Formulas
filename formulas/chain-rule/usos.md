# Usos

## Funciones anidadas

sin(x²) se deriva como cos(x²)·2x. El factor 2x describe la transformación interna y no puede eliminarse.

## Cambiar escala

exp(2x) tiene derivada 2exp(2x): duplicar la velocidad de la entrada añade un factor dos a la sensibilidad.

## Sensibilidad de procesos

En una cadena de conversiones o un modelo con variables intermedias, multiplicar derivadas locales transmite el cambio de entrada a salida. Para varias variables aparecen matrices jacobianas; el laboratorio estudia el caso escalar antes de esa extensión.
