# Colectividad canónica y función de partición

Tres niveles 0, Δ y 2Δ en contacto con un baño. Temperatura y degeneración cambian ocupación, energía y fluctuaciones; la distribución se normaliza con Z.

## Magnitudes y notación

| Símbolo | Interpretación |
| :-- | :-- |
| Z | Función de partición canónica: suma de pesos de microestados. |
| g | Degeneración del nivel: número de microestados con esa energía. |
| i | Índice de nivel de energía. |
| E | Energía del nivel; E dentro de promedios representa energía de un microestado. |
| β | Inversa de energía térmica: 1/(kBT). |
| k | Constante de Boltzmann kB. |
| B | Índice B: Boltzmann en kB. |
| T | Temperatura absoluta del baño. |
| P | Probabilidad total de ocupar un nivel, sumada sobre su degeneración. |
| U | Energía media del sistema. |
| C | Capacidad calorífica; CV a parámetros de espectro y volumen fijos. |
| V | Índice V: volumen constante. |
| S | Entropía canónica de los microestados. |
| e | Base de la exponencial, número de Euler. |

## Condiciones

Ensamble canónico con número de partículas, volumen y espectro fijos, y baño a T>0. Estados discretos finitos del experimento. La degeneración no se olvida al agrupar niveles. El modelo de tres niveles no es un gas completo ni el oscilador de infinitos niveles.

## Unidades

Control Δ en meV; kB=0,08617333262 meV/K para los cálculos. Z y P adimensionales; β en meV⁻¹; U meV; se muestra CV/kB y S/kB adimensionales. La fórmula física de CV tiene energía/K.
