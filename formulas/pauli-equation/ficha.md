# Ecuación de Pauli

Sector de espín de Pauli para un campo uniforme z, con H=−ωσz/2 y ħ=1. La cámara muestra el estado de espín; no una órbita espacial del electrón.

## Magnitudes y notación

| Símbolo | Interpretación |
| :-- | :-- |
| ħ | Constante de Planck reducida h/(2π). |
| i | Unidad imaginaria: i²=−1. |
| H | Hamiltoniano, operador de energía. |
| t | Tiempo físico o tiempo reducido según las unidades del laboratorio. |
| p | Impulso lineal del observable o partícula indicado. |
| m | Masa de la partícula. |
| n | Número cuántico entero que identifica el nivel. |
| σ | Matriz de Pauli con el índice de eje indicado; σ como anchura se especifica en la ficha. |
| φ | Azimut del vector de Bloch. |
| ω | Frecuencia angular firmada del Hamiltoniano o positiva del modo indicado. |
| Ψ | Espinor de dos componentes de Pauli. |
| q | Carga eléctrica firmada en la ecuación completa. |
| A | Potencial vector electromagnético. |
| Φ | Potencial eléctrico escalar. |
| B | Campo magnético. |
| z | Índice de la matriz de Pauli orientada en z. |
| ∂ | Derivada parcial temporal. |
| s | Índice s: Hamiltoniano del sector de espín en el experimento uniforme. |

## Condiciones

Ecuación no relativista con acoplamiento mínimo y factor giromagnético ideal g=2 en la expresión mostrada. El laboratorio fija el sector de espín, campo uniforme y ausencia de movimiento orbital o disipación. No representa la ecuación completa en cualquier campo.

## Unidades

Ecuación SI: p kg·m/s, q C, A potencial vector, Φ voltaje, B T. En el sector del laboratorio ħ=1, energía Eref, ω en Eref/ħ y tiempo ħ/Eref. La esfera de Bloch es adimensional.
