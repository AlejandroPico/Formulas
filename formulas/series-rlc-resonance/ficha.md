# Resonancia en circuitos RLC en serie

Resistor, inductor y condensador ideales en serie. XL=ωL y XC=1/(ωC); las tensiones L y C pueden ser grandes y opuestas. Regímen sinusoidal, RMS.

## Magnitudes

| Símbolo | Significado |
| :-- | :-- |
| Z | Impedancia compleja serie. |
| R | Resistencia positiva. |
| j | Unidad imaginaria electrotécnica. |
| ω | Frecuencia angular. |
| L | Inductancia. |
| C | Capacidad eléctrica. |
| f | Frecuencia en ciclos por segundo; f0 resonancia de corriente. |
| π | Pi, constante de conversión frecuencia angular. |
| X | Reactancia; XL inductiva y XC magnitud capacitiva. |
| Q | Factor de calidad serie adimensional. |

## Condiciones

Circuito ideal lineal en régimen sinusoidal estacionario, R,L,C positivos. Resonancia de corriente; no implica oscilación natural no amortiguada ni igualdad con todos los picos de tensión.

## Unidades

L control mH×10⁻³ H, C µF×10⁻⁶ F; f Hz y ω=2πf rad/s. V e I RMS; impedancia Ω. Q adimensional; no es potencia reactiva en esta ficha.
