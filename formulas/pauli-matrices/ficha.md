# Matrices de Pauli

Las matrices σx,σy,σz tienen autovalores ±1. Ajusta estado y dirección de medida para obtener esperanza y probabilidades compatibles.

## Magnitudes y notación

| Símbolo | Interpretación |
| :-- | :-- |
| i | Unidad imaginaria: i²=−1. |
| x | Coordenada espacial; en la caja pertenece al intervalo entre paredes. |
| n | Dirección unitaria de medida. |
| σ | Matriz de Pauli con el índice de eje indicado; σ como anchura se especifica en la ficha. |
| I | Operador identidad. |
| r | Vector de Bloch del estado. |
| δ | Delta de Kronecker: uno si los índices coinciden, cero en otro caso. |
| ε | Símbolo antisimétrico de Levi-Civita. |
| j | Índice del segundo eje cartesiano. |
| k | Índice del eje restante en el producto. |
| ⟨ | Inicio de esperanza estadística del observable. |
| ⟩ | Cierre de esperanza estadística. |

## Condiciones

Matrices hermíticas de dimensión dos, base de un qubit y dirección unitaria de medida. Los tres ejes no pueden tratarse como valores clásicos simultáneamente definidos. La media cero no añade un autovalor cero a σn.

## Unidades

σi y sus autovalores son adimensionales. S tiene unidad de acción. Los ángulos del experimento están en grados; todas las probabilidades se muestran en porcentaje.
