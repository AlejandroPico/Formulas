# Energía libre de Helmholtz

A=U−TS es el potencial adecuado para un sistema cerrado a temperatura y volumen fijados. Un valor de A no es por sí solo una energía útil intercambiada.

## Magnitudes

| Símbolo | Significado |
| :-- | :-- |
| A | Energía libre de Helmholtz; también se denota F en otras convenciones. |
| U | Energía interna del estado. |
| T | Temperatura absoluta. |
| S | Entropía del estado. |
| P | Presión. |
| V | Volumen. |

## Condiciones

Sistema simple compresible; composición fija para el diferencial mostrado. Para espontaneidad usar T,V constantes; a T,P constantes corresponde Gibbs.

## Unidades

U,A kJ en controles; S J/K se divide por 1000 para TS. T K, P Pa y V m³ en el diferencial SI. Referencias de U y S deben ser coherentes al comparar estados.
