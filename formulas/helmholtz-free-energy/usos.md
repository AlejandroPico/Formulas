# Usos

Estudiar equilibrio bajo temperatura y volumen fijos y obtener propiedades a partir de derivadas del potencial. Cambiar restricciones exige reconsiderar cuál potencial minimiza el sistema.

## Un caso que puedes comprobar

Evalúa el coste entrópico en un estado. Con los valores iniciales, calcula energía de helmholtz en kJ. Energía de Helmholtz = 70 kJ. A=U−TS es el potencial adecuado para un sistema cerrado a temperatura y volumen fijados. Un valor de A no es por sí solo una energía útil intercambiada.

## Condiciones de aplicación

Sistema simple compresible; composición fija para el diferencial mostrado. Para espontaneidad usar T,V constantes; a T,P constantes corresponde Gibbs.
