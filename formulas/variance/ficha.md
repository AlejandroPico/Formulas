# Varianza

Cinco observaciones tratadas como población completa. Suma cuadrados de desviaciones y compara el divisor poblacional con el estimador de una muestra.

## Magnitudes y notación

| Símbolo | Interpretación |
| :-- | :-- |
| σ | Desviación estándar poblacional; σ² es varianza de la población completa. |
| N | Número de elementos de la población completa. |
| x | Valor observado; xi es una observación concreta. |
| μ | Media de la población completa. |
| i | Índice de observación. |
| s | Desviación estándar muestral; s² estima varianza poblacional. |
| n | Tamaño de la muestra cuando se usa el estimador. |
| X | Variable aleatoria en la ley de transformación de varianza. |
| a | Factor de escala multiplicativo de la variable. |
| b | Desplazamiento constante de toda la variable. |
| Var | Operador de varianza: promedio del cuadrado de desviación. |

## Condiciones

Datos con segundo momento finito. El divisor depende de si se describe la población completa o se estima desde una muestra; no se cambia solo para obtener un número deseado. La varianza nula significa datos iguales, y no mide por sí sola toda la forma de una distribución.

## Unidades

Si x tiene unidad u, media y desviación típica usan u, pero varianza usa u². El laboratorio tiene cinco valores en unidades arbitrarias comunes. El control de escala es un factor adimensional y los cuadrados de la última vista mantienen escala geométrica común.
