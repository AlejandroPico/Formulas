# Derivación

Parte de a(x−x₁)(x−x₂). Multiplica: a[x²−(x₁+x₂)x+x₁x₂]. Compara coeficientes con ax²+bx+c.

El coeficiente lineal exige −a(x₁+x₂) = b, así que x₁+x₂ = −b/a. El término independiente exige ax₁x₂ = c, de donde x₁x₂ = c/a. Dividir es legítimo porque a no es cero.

Para r±si, multiplica (r+si)(r−si) = r²−(si)² = r²+s², pues i² = −1. La suma cancela las partes imaginarias. Las mismas relaciones funcionan aunque las dos raíces coincidan: se conservan ambos factores, no se borra uno.
