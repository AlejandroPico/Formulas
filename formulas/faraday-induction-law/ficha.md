# Ley de Faraday

La inducción responde a una variación de flujo, no únicamente a tener campo magnético. Cambiar B, girar la normal o modificar el área puede generar fem; el experimento mantiene el área y combina los dos primeros mecanismos.

## Magnitudes

| Símbolo | Significado |
| :-- | :-- |
| ℰ | Fuerza electromotriz inducida, con signo respecto al sentido positivo del contorno. |
| Λ | Enlace total de flujo de las N espiras iguales. |
| N | Número entero de vueltas de la bobina. |
| Φ | Flujo magnético por una espira; Φ_B identifica el campo magnético. |
| B | Componente firmada del campo magnético uniforme según el eje de referencia. |
| A | Área de una espira plana. |
| θ | Ángulo en radianes entre la normal de la espira y el campo de referencia. |
| t | Tiempo; puntos superiores significan derivadas temporales. |

## Alcance

Campo uniforme, espiras de igual área, θ medido respecto a la normal. B(t)=B0+αt y θ(t)=θ0+ωt. Si B(t) cambia de signo se conserva la referencia fija y se interpreta ese signo; no se sustituye por |B|.

## Unidades

B teslas, A m², Φ webers y fem Wb/s=V. Radio del control en cm se divide entre 100 antes de calcular πr². Ángulo inicial en grados se convierte a radianes; ω rad/s, α T/s.
