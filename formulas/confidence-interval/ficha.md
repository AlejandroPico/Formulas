# Intervalo de confianza

Intervalo bilateral para media normal con σ poblacional conocida. Muestras ilustrativas reproducibles; la cobertura se refiere al procedimiento, no a una probabilidad posterior de μ.

## Magnitudes y notación

| Símbolo | Interpretación |
| :-- | :-- |
| I | Parte de IC: intervalo de confianza. |
| C | Parte de IC: intervalo de confianza. |
| x | Media observada cuando lleva barra; dato individual sin barra. |
| z | Cuantil de la normal estándar que deja probabilidad 1−α/2 a su izquierda. |
| σ | Desviación poblacional conocida, no estimada desde la muestra. |
| n | Tamaño muestral positivo. |
| α | Probabilidad nominal no cubierta por el procedimiento bilateral. |
| μ | Media poblacional fija. |
| Pr | Probabilidad bajo repetición de muestras del modelo. |
| – | Barra: promedio muestral de datos. |

## Condiciones

Población normal, observaciones independientes y desviación poblacional conocida. Con σ estimada se requiere otro procedimiento, como Student; no sustituir σ por s sin ajustar cuantiles. La vista de cobertura genera 40 medias pseudorrandom reproducibles bajo la distribución exacta de la media, con μ=10. La frecuencia ilustrativa no tiene que igualar el nivel nominal.

## Unidades

Media, σ y extremos tienen la misma unidad de la variable de datos, fijada como unidad de referencia. α, cobertura y z son adimensionales. n es conteo positivo. La semianchura escala como σ/√n; cuadruplicar n reduce a la mitad el margen con igual cobertura.
