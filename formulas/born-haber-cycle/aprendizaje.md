# Aprendizaje

## Tres formas de aprender

**Ciclo energético · Explorar · Balance**

Ciclo hipotético de una sal MX: sublimación del metal, media disociación de X2, ionización, afinidad firmada y formación de red desde iones gaseosos.

## Predice, prueba y justifica

1. **Predice antes de medir.** Ciclo hipotético de una sal MX: sublimación del metal, media disociación de X2, ionización, afinidad firmada y formación de red desde iones gaseosos. Calcula formación de red con los datos iniciales en kJ/mol.

2. **Construye el objetivo.** Ajusta entalpía de formación hasta obtener formación de red=-1000 kJ/mol.

3. **Distingue el modelo.** ¿Qué interpretación es correcta?

4. **Comprueba una nueva predicción.** Ahora entalpía de formación=-600 kJ/mol. Calcula formación de red en kJ/mol y explica el cambio.

Los retos admiten pistas y reintentos. En exploración, mueve un control cada vez, anticipa el cambio y compara el resultado. Las vistas 3D admiten ratón, tacto y flechas del teclado.

## Una idea que debes poder explicar

Formar la red desde iones gaseosos tiene el signo opuesto a disociarla

Sal idealizada MX de iones monovalentes, estados de referencia coherentes y misma temperatura. EA se define como entalpía firmada de incorporar el electrón, negativa en el ejemplo. Si se usa afinidad como energía liberada positiva, debe cambiarse el signo. Los valores son hipotéticos; no constituyen datos de una sal identificada.
