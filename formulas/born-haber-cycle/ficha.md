# Ciclo de Born-Haber

Ciclo hipotético de una sal MX: sublimación del metal, media disociación de X2, ionización, afinidad firmada y formación de red desde iones gaseosos.

## Magnitudes y notación

| Símbolo | Interpretación |
| :-- | :-- |
| Δ | Variación de la magnitud: estado final menos inicial. |
| H | Entalpía de la etapa indicada. |
| f | Índice f: formación de MX desde elementos de referencia. |
| s | Parte de sub: sublimación del metal. |
| u | Parte de sub: sublimación del metal. |
| b | Parte de sub: sublimación del metal. |
| D | Entalpía de disociación de X2 en átomos gaseosos. |
| X | Elemento no metálico en la molécula X2. |
| I | Parte de IE: energía de ionización del metal. |
| E | Parte de IE o EA: energía de ionización o afinidad firmada, respectivamente. |
| A | Parte de EA: afinidad electrónica como entalpía firmada. |
| r | Parte de red: formación de cristal desde iones gaseosos. |
| e | Parte de red: etapa de formación de red. |
| d | Parte de red: etapa de formación de red. |

## Condiciones

Sal idealizada MX de iones monovalentes, estados de referencia coherentes y misma temperatura. EA se define como entalpía firmada de incorporar el electrón, negativa en el ejemplo. Si se usa afinidad como energía liberada positiva, debe cambiarse el signo. Los valores son hipotéticos; no constituyen datos de una sal identificada.

## Unidades

Todas las etapas se dan en kJ por mol de MX formado. D(X2) es energía por mol de moléculas disociadas y aporta D/2 al formar MX. IE y EA corresponden al electrón requerido. El gráfico mide entalpía relativa, no altura geométrica del cristal.
