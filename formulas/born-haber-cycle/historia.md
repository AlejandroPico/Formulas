# Historia

Born y Haber formularon ciclos que enlazan medidas termoquímicas con la energía de las redes iónicas. El fundamento es la independencia del camino de una función de estado, no la posibilidad de ejecutar cada etapa como reacción observable aislada. El signo de red depende de si se define formación o disociación.
