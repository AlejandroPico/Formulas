# Predice los cortes, después resuelve

1. En Explorar, cambia c para pasar de dos cortes a tangencia y luego a ningún corte. Compara con el signo de Δ.
2. Cambia el signo de a: la parábola se abre hacia abajo, pero la fórmula sigue funcionando.
3. En Vértice, arrastra el punto de máximo o mínimo. Observa cómo cambian b y c manteniendo a.
4. Pon a = 0. Prueba después b = 0 y c = 0 para distinguir lineal, imposible y cualquier x.
5. Resuelve Dianas y comprueba las raíces sustituyéndolas en el polinomio.

**Pregunta de salida** · una raíz doble es un único valor con multiplicidad dos. No son dos puntos diferentes en el gráfico.
