# Derivación

En elasticidad isotrópica tridimensional, εx = [σx−ν(σy+σz)]/E, con expresiones cíclicas para y y z. Impón σz = 0: salen las dos primeras expresiones y εz = −ν(σx+σy)/E.

Para cortante, γxy = τxy/G y G = E/[2(1+ν)]. El tensor de pequeñas deformaciones tiene εxy = γxy/2.

Invirtiendo las dos relaciones normales: σx = E(εx+νεy)/(1−ν²), σy = E(εy+νεx)/(1−ν²). Para dibujar sin giro rígido se usa ux = εx·x + εxy·y y uy = εxy·x + εy·y, con uz = εz·z. El factor de amplificación se aplica solo a esos desplazamientos, nunca a los resultados físicos.
