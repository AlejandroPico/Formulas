# Usos

Comparar una fuerza tangencial con el área resistente y estudiar respuesta elástica en cortante uniforme. Tornillos, uniones y vigas necesitan además geometría, distribución de tensión y criterios de resistencia propios.

## Un caso que puedes comprobar

Invierte el sentido del corte. Con los valores iniciales, calcula tensión media en MPa. Tensión media = 50 MPa. Una fuerza tangencial uniforme produce τ media=F/A. γ=τ/G es deformación angular de ingeniería; el dibujo se amplifica ×100.

## Condiciones de aplicación

Carga tangencial uniforme para interpretación puntual; elasticidad lineal y pequeña deformación para τ=Gγ. No calcula distribución de una viga ni plastificación.
