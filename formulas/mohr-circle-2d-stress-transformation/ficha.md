# Círculo de Mohr: transformación de tensiones 2D

Transforma un tensor de tensión simétrico plano con una rotación de ejes. El círculo mide tensiones sobre distintas caras y gira el doble del ángulo físico.

## Magnitudes

| Símbolo | Significado |
| :-- | :-- |
| σ | Tensión normal; índices x,y de caras y 1,2 de tensiones principales. |
| m | Índice m: tensión normal media. |
| x | Dirección cartesiana original o rotada con prima. |
| y | Segunda dirección cartesiana original o rotada. |
| R | Radio del círculo de Mohr en unidades de tensión. |
| τ | Tensión cortante del tensor simétrico. |
| θ | Ángulo antihorario de rotación de ejes físicos. |

## Condiciones

Estado plano simétrico y convenciones de tracción positivas, cortante positivo y rotación de ejes explicitadas. En círculo de radio cero toda orientación es principal; no hay una única dirección privilegiada.

## Unidades

Todas las componentes, radio y centro MPa. θ del control grados, cálculo radianes; la rotación gráfica del círculo usa doble ángulo. No interpreta el radio como longitud material.
