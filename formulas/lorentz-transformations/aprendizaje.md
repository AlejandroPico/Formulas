# Aprendizaje

## Tres formas de aprender

**Evento · Explorar · Ejes de Minkowski**

Las coordenadas de un evento cambian entre sistemas inerciales. La separación espaciotemporal se conserva; el tiempo transformado incluye simultaneidad relativa.

## Predice, prueba y justifica

1. **Predice el resultado.** Las coordenadas de un evento cambian entre sistemas inerciales. La separación espaciotemporal se conserva; el tiempo transformado incluye simultaneidad relativa. Calcula posición x′ con los datos iniciales, en L.

2. **Construye el escenario.** Ajusta posición x hasta conseguir posición x′=1 L.

3. **Distingue las hipótesis.** ¿Qué afirmación explica correctamente el modelo?

4. **Comprueba una segunda predicción.** Ahora posición x=2 L. Calcula posición x′, en L, y justifica el cambio.

Los retos admiten pistas y reintentos. En exploración, mueve un control cada vez, anticipa el cambio y compara el resultado. Las vistas 3D admiten ratón, tacto y flechas del teclado.

## Una idea que debes poder explicar

Un boost conserva x²−(ct)², no cada coordenada

Sistemas inerciales en espacio-tiempo plano, boost en x y |β|<1. Orígenes coincidentes en t=t′=0. Una transformación de coordenadas no describe aceleración ni contracción mecánica.
