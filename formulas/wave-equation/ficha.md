# Ecuación de onda

La ecuación de onda se extiende a varias coordenadas; una membrana rectangular admite modos con líneas nodales.

## Magnitudes

| Símbolo | Lectura |
| :-- | :-- |
| u | Desplazamiento transversal de la membrana, función de x, y y t. |
| c | Rapidez de onda constante del medio ideal. |
| t | Tiempo desde el estado inicial. |
| x | Coordenada horizontal sobre el marco rectangular. |
| y | Segunda coordenada sobre el marco rectangular. |
| A | Amplitud del modo de vibración. |
| m | Índice entero positivo del modo horizontal. |
| n | Índice entero positivo del modo vertical. |
| L | Longitud del lado rectangular indicado por su subíndice. |
| ω | Frecuencia angular propia del modo (m,n). |

## Cuándo se aplica

Membrana ideal rectangular con marco fijo, tensión uniforme, medio lineal y sin disipación. Modos enteros positivos. Desplazamientos pequeños: la amplificación gráfica no amplía el dominio físico de validez.

## Evita estos errores

Confundir superficie 3D con tres coordenadas de propagación; contar bordes como líneas interiores; usar modos fraccionarios; tratar una membrana como placa rígida.

## Laboratorio

**Resonancias · Explorar · Membrana 3D**

Gira la membrana con ratón, tacto o flechas. Cambia m y n para descubrir líneas nodales y frecuencias propias.

Los bordes permanecen fijos. La altura es un desplazamiento amplificado para verlo; el modelo es lineal y describe pequeñas oscilaciones.
