# Usos

## Triangulación

Con una base y dos ángulos puedes calcular los otros lados. Esto permite estimar distancias hasta puntos inaccesibles y comparar el tamaño de una figura con sus direcciones.

## Radio circunscrito

Para a = 4 y A = 30°, 2R = 8, luego R = 4. Esta relación conecta una medición lineal con la circunferencia del triángulo.

## Comprobar ambigüedad

Con a = 4, b = 6 y A = 30°, sin B = 0,75. B puede ser aproximadamente 48,59° o 131,41°; ambos dejan un tercer ángulo positivo. Elegir uno sin datos adicionales perdería una solución.
