# Energía de ionización del hidrógeno

El cero de energía corresponde al electrón libre a distancia infinita. Desde un nivel n del hidrógeno se necesita 13,6/n² eV; el exceso del fotón se convierte en energía cinética.

## Magnitudes y notación

| Símbolo | Interpretación |
| :-- | :-- |
| E | Energía ligada En o energía de ionización Eion según el índice. |
| n | Número cuántico principal entero positivo. |
| ion | Índice ion: energía mínima para llevar el electrón al continuo. |
| eV | Electronvoltio: unidad de energía, 1 eV=1,602176634×10⁻¹⁹ J. |
| e | e en la unidad eV: electronvoltio, no número de Euler. |
| V | V en la unidad eV: voltio en la definición de electronvoltio. |
| K | Energía cinética del fotoelectrón después de ionizar. |
| h | Constante de Planck. |
| ν | Frecuencia del fotón incidente. |
| c | Velocidad de la luz en vacío, 299 792 458 m/s. |
| λ | Longitud de onda del fotón; la de umbral es la máxima que alcanza ionización desde ese nivel. |
| umbral | Índice umbral: transición mínima hacia el continuo. |

## Condiciones

Hidrógeno de un electrón, aproximación no relativista y coeficiente redondeado de 13,6 eV. No incluye estructura fina, campos externos, masa reducida exacta ni detalle de reglas de selección para transiciones ligadas. n entero positivo.
