# Ecuación de Nernst

El potencial de una reacción redox depende del cociente de actividades. El coeficiente con log decimal a 25 °C cambia si T cambia.

## Magnitudes

| Símbolo | Significado |
| :-- | :-- |
| E | Potencial de celda para la reacción escrita; círculo marca valor estándar. |
| R | Constante molar de los gases. |
| T | Temperatura absoluta. |
| n | Número positivo de electrones por reacción estequiométrica. |
| F | Constante de Faraday. |
| Q | Cociente positivo adimensional de actividades. |
| G | Gibbs de reacción. |
| r | Índice r: reacción. |
| Δ | Cambio por avance de reacción. |
| K | Kelvin en la condición de temperatura de referencia. |

## Condiciones

Actividades positivas y estándar coherente; n electrones positivo. No aplicar ln a Q=0 ni reemplazar actividades por concentraciones sin indicar aproximación.

## Unidades

E V; R J/(mol·K), T K y F C/mol producen V. Q adimensional; n entero. El coeficiente decimal 0,05916 tiene unidades V a 25 °C.
