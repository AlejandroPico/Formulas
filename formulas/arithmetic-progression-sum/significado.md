# Añadir siempre el mismo salto

Una progresión aritmética cambia por una diferencia constante d. Con a₁ = 3 y d = 2, los términos son 3, 5, 7, 9… El término n es a₁ + (n−1)d: entre el primero y el n hay **n−1 saltos**.

Sₙ suma los primeros n términos, no calcula solo el último. Como las parejas de extremos tienen la misma suma, Sₙ = n(a₁+aₙ)/2.

La diferencia puede ser negativa o cero, y los términos también pueden ser negativos. En ese caso la suma es algebraica, no un conteo de objetos negativos.

**Gradas** propone cantidades que aumentan fila a fila; **Explorar** muestra términos y acumulado; **Parejas** une extremos y explica el factor dos.
