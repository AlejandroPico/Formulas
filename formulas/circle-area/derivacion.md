# Del disco a una base y una altura

1. Divide el disco en un número par de sectores iguales.
2. Colócalos alternando las puntas arriba y abajo. La figura se parece cada vez más a un rectángulo al aumentar el número de piezas.
3. La base se aproxima a la mitad del borde: πr. La altura se aproxima a r.
4. En el límite, A = base × altura = πr × r = πr².

**Con pocos sectores, la figura no es un rectángulo exacto.** El modo Sectores conserva los arcos para mostrar esa diferencia.

Como d = 2r, sustituir r = d/2 da A = πd²/4. Para despejar r, divide A entre π y toma la raíz no negativa: un radio no tiene signo negativo.

Comprobación: con r = 2, tanto πr² como πd²/4 dan 4π.
