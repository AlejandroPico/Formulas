# Átomo de hidrógeno: densidad de probabilidad radial

Compara estados 1s, 2s y 2p hidrogenoides. La probabilidad por intervalo radial incluye r²; la vista 3D promedia orientación y no dibuja trayectorias electrónicas.

## Magnitudes y notación

| Símbolo | Interpretación |
| :-- | :-- |
| ρ | Radio adimensional Zr/a0, no operador densidad. |
| p | Etiqueta orbital con ℓ=1, no impulso. |
| n | Número cuántico entero que identifica el nivel. |
| r | Distancia al núcleo, no vector de Bloch. |
| a | Radio de Bohr cuando lleva índice 0. |
| P | Densidad de probabilidad por intervalo radial. |
| R | Parte radial normalizada de la función de onda. |
| Z | Carga nuclear positiva en unidades de la carga elemental. |
| ℓ | Número cuántico orbital. |
| s | Etiqueta orbital con ℓ=0. |
| ∣ | Módulo de la parte radial compleja. |
| ∞ | Extensión radial sin límite superior finito. |
| d | Diferencial de radio en la integral. |

## Condiciones

Átomo hidrogenoide de un electrón, núcleo pesado y aproximación no relativista. La densidad por volumen |ψ|² no coincide con la probabilidad por intervalo radial. La vista 3D de 2p promedia sobre orientaciones y no representa un orbital 2p individual dirigido.

## Unidades

R tiene unidad m⁻³ᐟ²; P_r tiene m⁻¹. El laboratorio usa r/a0 y densidad por d(r/a0), igual a ZPρ(Zr/a0). a0=0,0529177 nm, Z adimensional.
