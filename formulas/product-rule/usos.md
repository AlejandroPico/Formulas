# Usos

## Área que cambia

Si largo y ancho dependen del tiempo, la tasa de área es largo′·ancho + largo·ancho′. El dibujo de bandas ayuda cuando ambos lados son positivos.

## Magnitudes físicas

Para p = mv, si masa y velocidad varían, p′ = m′v+mv′. Si la masa es constante, el primer aporte desaparece.

## Análisis de signos

Un aporte puede ser positivo y el otro negativo. Sumarlos permite reconocer crecimiento, disminución o cancelación. El modo Dos aportes conserva esa lectura cuando una interpretación geométrica con longitudes positivas ya no sirve.
