# Aprendizaje

1. Predice si c aumenta al abrir C sin cambiar a y b.
2. Resuelve las cuatro misiones de Rescate; conserva el signo del coseno.
3. En Explorar, arrastra el vértice y busca el caso rectángulo.
4. En Proyección, cruza los 90°: explica por qué la proyección puede ser negativa.

Comprueba a = b y C = 60°: aparece un triángulo equilátero. Después reduce C hacia cero y observa que c se aproxima a |a−b|. Es un límite degenerado, no otro triángulo ordinario.
