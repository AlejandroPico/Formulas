# Significado

La distancia entre los extremos de dos caminos depende de sus longitudes y de su apertura. Si los caminos miden a y b y forman C, el tercer lado c queda enfrente de C. El término −2ab cos C corrige la suma de cuadrados.

Con C = 90°, cos C = 0: reaparece Pitágoras. Para C agudo la corrección reduce c²; para C obtuso lo aumenta. Con a = 4, b = 3 y C = 60°, c² = 16+9−12 = 13, así que c ≈ 3,61.

Las tres expresiones son la misma relación cambiando el lado que se busca. El simulador permite abrir el triángulo y ver la proyección, incluso cuando queda fuera del segmento base.
