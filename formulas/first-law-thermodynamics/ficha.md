# Primera ley de la termodinámica

Entrega calor y extrae trabajo. Se conserva energía; calor y trabajo son transferencias, no sustancias guardadas en el gas.

## Magnitudes

| Símbolo | Significado |
| :-- | :-- |
| U | Energía interna del sistema cerrado. |
| Q | Calor transferido al sistema, positivo entrante. |
| W | Trabajo realizado por el sistema sobre el exterior, positivo saliente. |
| n | Cantidad de sustancia en moles. |
| C | Capacidad calorífica molar; C_V a volumen constante. |
| V | Índice que indica volumen constante en la capacidad calorífica. |
| T | Temperatura absoluta. |
| Δ | Valor final menos inicial. |

## Condiciones

Sistema cerrado; en la primera expresión se omiten cambios de energía cinética y potencial del conjunto. La relación de temperatura es un modelo de gas ideal con Cv constante.

## Unidades

U,Q,W J; n mol; Cv J/(mol·K); ΔT K. Diferencia de temperatura en K coincide numéricamente con °C, pero la temperatura de estado se expresa en K.
