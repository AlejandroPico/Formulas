# Integral de Gauss

Una integral sin primitiva elemental puede tener un valor total exacto. Elevarla al cuadrado transforma el problema en un área de dos variables con simetría radial.

## Magnitudes

| Símbolo | Significado |
| :-- | :-- |
| a | Coeficiente positivo que controla la anchura. |
| x | Variable real de integración. |
| I | Integral positiva de la campana. |
| r | Radio en la prueba de dos variables. |
| θ | Ángulo polar, de cero a 2π. |

## Alcance

a>0; integración sobre toda la recta. El área de [−b,b] no es igual al total para un b finito.

## Unidades

Si x usa u, a usa u⁻² y la integral u. r comparte unidad de x; el elemento de área r dr dθ usa u². El factor de Jacobi r es esencial: omitirlo cambia el valor del resultado.
