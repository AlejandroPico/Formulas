# Historia

La esfera de Bloch hace visible el espacio de estados puros de dos niveles y la relación entre dirección de medición y amplitudes. Se utiliza tanto para espines como para otras realizaciones de qubits, siempre manteniendo separadas representación matemática y dispositivo.

## Referencia y alcance

[Material de estudio](https://www.ocw.mit.edu/courses/8-06-quantum-physics-iii-spring-2016/resources/mit8_06s16_chap3/).

Estado puro de un qubit y detector proyectivo. La esfera es un espacio de estados, no una esfera de posiciones. φ es fase relativa; la fase global se omite porque no cambia las probabilidades de este sistema aislado.

La fecha de creación del catálogo procede del archivo original; el año científico y la fecha de revisión tienen funciones diferentes.
