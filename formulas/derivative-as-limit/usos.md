# Usos

Medir velocidad instantánea a partir de posiciones; interpretar sensibilidad local de una función; reconocer puntos donde una recta tangente no existe. Las diferencias finitas sirven para aproximar derivadas a partir de datos, pero ruido, redondeo y un intervalo demasiado grande o demasiado pequeño pueden afectar el resultado.

## Un criterio de aplicación

f definida en un entorno del punto; h no nulo en las secantes. Para derivabilidad interior, ambos límites laterales deben existir, ser finitos y coincidir.
