# Potencial de reversión neuronal de Nernst

Compara un único ion permeante en equilibrio electroquímico. El voltaje calculado es interior respecto al exterior; no es el potencial total de una neurona.

## Magnitudes

| Símbolo | Significado |
| :-- | :-- |
| E | Potencial de equilibrio del ion, interior respecto al exterior. |
| R | Constante molar de los gases. |
| T | Temperatura absoluta. |
| z | Valencia firmada del ion. |
| F | Constante de Faraday, carga por mol de electrones. |
| c | Concentración del mismo ion en cada lado. |
| o | Índice o: exterior de membrana. |
| i | Índice i: interior de membrana. |
| K | Índice K: ion potasio monovalente. |
| ion | Índice ion: especie iónica que se equilibra. |
| m | Prefijo m de mV: milésima de voltio. |
| V | Voltio en la unidad mV. |
| C | Celsius en la condición de referencia. |

## Condiciones

Un único ion en equilibrio electroquímico, actividades ideales y concentraciones positivas. No calcula el potencial de membrana de múltiples iones ni corrientes de canales ni potenciales de acción.

## Unidades

T K; R J/(mol·K); F C/mol; E V y lectura mV×1000. cout/cin adimensional usando la misma unidad, aquí mmol/L. Valencia z incluye signo.
