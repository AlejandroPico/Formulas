# Contraste de hipótesis: test z

Contraste bilateral con desviación poblacional conocida. El área de cola bajo H0 define p; no es la probabilidad de que H0 sea cierta.

## Magnitudes

| Símbolo | Significado |
| :-- | :-- |
| z | Estadístico estandarizado de la media bajo H0. |
| x | Variable observada; barra superior media muestral. |
| μ | Media poblacional propuesta en μ0. |
| σ | Desviación típica poblacional conocida, no estimada con la muestra. |
| n | Tamaño de muestra positivo. |
| p | Valor p bilateral bajo el modelo nulo. |
| Φ | Función de distribución acumulada normal estándar. |

## Condiciones

Muestra independiente representativa, σ poblacional conocida y normalidad de la media exacta o aproximación justificada. Si σ se estima, considerar t; no inferir automáticamente normalidad por cualquier n grande.

## Unidades

x̄,μ0,σ mismas unidades; error estándar σ/√n conserva esa unidad. z,p,α adimensionales, α mostrado porcentaje. p no es probabilidad de que H0 sea verdadera.
