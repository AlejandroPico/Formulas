## Cuatro misiones

1. **Predice el experimento.** Decide qué tan lejos está una media bajo el modelo nulo. Con los valores iniciales, calcula estadístico z en unidades adimensionales.

2. **Construye una solución.** Ajusta media observada para conseguir estadístico z = 0 .

3. **Elige con criterio.** ¿Cuál de estas afirmaciones describe correctamente este experimento?

4. **Comprueba otro escenario.** Cambia el escenario a Media observada=100. Calcula estadístico z en unidades adimensionales.

## La explicación importa

Media normal exacta o aproximación justificada; σ conocida. Si se estima σ, suele corresponder un contraste t.

Antes de mover el control, predice el sentido del cambio. Comprueba números y unidades; explica qué hipótesis hace posible el resultado. Muestra independiente representativa, σ poblacional conocida y normalidad de la media exacta o aproximación justificada. Si σ se estima, considerar t; no inferir automáticamente normalidad por cualquier n grande.
