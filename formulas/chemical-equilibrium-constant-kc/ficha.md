# Constante de equilibrio Kc

Ejemplo A⇌B en solución ideal: Qc=[B]/[A] y Kc fijo. Mueve la composición conservando A+B y descubre la dirección favorecida.

## Magnitudes

| Símbolo | Significado |
| :-- | :-- |
| K | Constante de equilibrio de actividades; Kc aproximación de concentraciones. |
| a | Actividad adimensional de la especie indicada. |
| ν | Coeficiente estequiométrico positivo en el lado correspondiente. |
| j | Índice de especies producto. |
| i | Índice de especies reactivo. |
| Q | Cociente de reacción de la composición actual. |
| c | Índice c: cociente de concentraciones. |
| A | Especie reactiva A. |
| B | Especie producto B. |
| C | Concentración total [A]+[B] del ejemplo 1:1. |
| e | Índice e: concentración en equilibrio. |

## Condiciones

Actividades positivas; soluciones ideales para sustituirlas por concentraciones normalizadas. Los sólidos y líquidos puros no se introducen como concentraciones variables en K. El ejemplo es 1:1.

## Unidades

K de actividades adimensional. En convenciones de Kc sin concentración estándar pueden aparecer unidades según estequiometría; en A⇌B se cancelan. Concentraciones mol/L en el ejemplo.
