# Radio de Bohr

rn=n²a0/Z para un sistema de un electrón. La vista cuántica representa probabilidad radial de l=n−1 promediada sobre orientaciones; no muestra un electrón siguiendo órbitas.

## Magnitudes y notación

| Símbolo | Interpretación |
| :-- | :-- |
| a | a0: longitud característica llamada radio de Bohr. |
| π | Pi, constante geométrica. |
| ε | ε0: permitividad eléctrica del vacío. |
| ℏ | Constante de Planck reducida. |
| m | me: masa del electrón. |
| e | Carga elemental positiva en a0; base exponencial en la distribución radial. |
| r | Distancia radial al núcleo; rn escala de radio del nivel. |
| n | Número cuántico principal positivo. |
| Z | Número atómico; carga nuclear Ze de un sistema con un solo electrón. |
| E | Energía ligada del nivel n. |
| nm | Nanómetro, 10⁻⁹ m. |
| ρ | Radio adimensional r/rn; Pρ es densidad respecto de ρ. |
| P | Densidad de probabilidad radial, no densidad volumétrica. |
| ℓ | Número cuántico orbital; aquí se selecciona ℓ=n−1. |
| ! | Factorial entero: producto desde uno hasta el entero indicado. |

## Condiciones

Un solo electrón, núcleo de carga Z, aproximación no relativista y núcleo pesado. La escala rn no es una posición exacta ni la media radial de todos los estados con n. La densidad representada usa ℓ=n−1; otros ℓ tienen otra distribución. Los puntos son una representación ilustrativa promediada.

## Unidades

a0=0,05291772105 nm; rn nm; E eV. ρ y Pρ adimensionales porque la densidad se refiere a dρ; la densidad Pr por dr tiene unidad inversa de longitud. Z,n enteros.
