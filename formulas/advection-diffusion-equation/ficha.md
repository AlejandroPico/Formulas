# Ecuación de advección-difusión

Una gaussiana viaja a velocidad constante y se ensancha por difusión. Solución exacta sobre la recta, sin inestabilidad de un esquema numérico.

## Magnitudes

| Símbolo | Significado |
| :-- | :-- |
| φ | Densidad del pulso transportado, normalizada a masa uno. |
| x | Coordenada espacial sobre la recta. |
| t | Tiempo desde el inicio. |
| c | Velocidad de advección constante. |
| D | Difusividad no negativa. |
| s | Anchura RMS; s0 es desviación inicial del pulso. |
| π | Pi, constante que normaliza la gaussiana. |

## Condiciones

Coeficientes constantes, D≥0, anchura inicial positiva y recta infinita sin fuentes. D=0 es traslación pura. El dibujo tiene ventana finita y no impone fronteras artificiales a la solución.

## Unidades

x,s0 m; c m/s; D m²/s; t s. φ m⁻¹ y su integral masa adimensional uno. Varianza m²; ambos lados de la EDP m⁻¹s⁻¹.
