# Contraste de hipótesis: test t

Contraste bilateral de una media con desviación poblacional desconocida. La muestra estima s, y sus grados de libertad determinan colas e intervalo de confianza.

## Magnitudes y notación

| Símbolo | Interpretación |
| :-- | :-- |
| t | Estadístico observado de Student: diferencia de medias en errores estándar. |
| x | Observación de la muestra; la barra indica media muestral. |
| μ | Media poblacional hipotética μ0 bajo H0. |
| s | Desviación estándar muestral, estimada con divisor n−1. |
| n | Tamaño de muestra entero, mayor que uno. |
| ν | Grados de libertad de Student, n−1. |
| i | Índice de observación muestral. |
| p | p-valor bilateral, probabilidad de un estadístico al menos tan extremo bajo H0. |
| T | Variable aleatoria con distribución t de ν grados de libertad. |
| Pr | Operador de probabilidad. |
| bil | Índice bil: bilateral. |
| obs | Índice obs: estadístico observado. |

## Condiciones

Contraste de una media con σ poblacional desconocida, s>0 y muestra independiente. Normalidad hace exacto el contraste; para otros datos evalúa robustez y diseño. No se confunde con el test z ni con un test pareado o de dos grupos.

## Unidades

x̄,μ0,s comparten unidad; s/√n tiene esa unidad y t es adimensional. n,ν enteros; p adimensional, α se introduce como porcentaje. El simulador recibe resúmenes de una muestra hipotética.
