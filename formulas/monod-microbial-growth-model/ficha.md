# Modelo de crecimiento microbiano de Monod

Tasa específica de crecimiento de Monod con sustrato mantenido constante. El cultivo hipotético crece exponencialmente a esa tasa; no integra agotamiento ni muerte.

## Magnitudes y notación

| Símbolo | Interpretación |
| :-- | :-- |
| μ | Tasa específica de crecimiento de biomasa. |
| S | Concentración del sustrato limitante. |
| K | Constante KS: concentración con mitad de tasa máxima. |
| X | Biomasa del cultivo. |
| t | Tiempo físico en horas. |
| d | Diferencial en la tasa de biomasa. |
| max | Índice max: límite superior de la tasa específica. |
| constante | Sustrato mantenido externamente constante en la solución exponencial. |

## Condiciones

Una limitación de sustrato, parámetros positivos y condiciones constantes. Se omiten muerte, inhibición, mantenimiento y otros nutrientes. El experimento mantiene S fijo mediante suministro idealizado. La ventana temporal se adapta para conservar legibilidad; no implica saturación de biomasa a una capacidad.

## Unidades

S y KS en g/L, μ y μmax en h⁻¹; X/X0 es adimensional. El tiempo de duplicación ln2/μ es indefinido si S=0 y μ=0. El exponente μt no tiene unidades. KS tiene unidades de concentración, no de crecimiento.
