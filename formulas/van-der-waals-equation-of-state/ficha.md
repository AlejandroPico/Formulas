# Ecuación de estado de van der Waals

Un mol con volumen molar en L/mol y parámetros de CO₂. El término atractivo resta presión y el covolumen limita el dominio; las ramas inestables se señalan.

## Magnitudes

| Símbolo | Significado |
| :-- | :-- |
| P | Presión del modelo. |
| a | Parámetro de atracción intermolecular positivo. |
| V | Volumen molar en Vm. |
| m | Índice m: cantidad por mol. |
| b | Covolumen molar positivo. |
| R | Constante de los gases. |
| T | Temperatura absoluta; Tc crítica del modelo. |
| c | Índice c: punto crítico. |

## Condiciones

Vm>b; T absoluta positiva. Modelo medio de gas real; no reproduce con precisión todas las propiedades del CO₂ ni incluye automáticamente coexistencia líquido–vapor.

## Unidades

Control Vm L/mol; R=0,08314462618 L·bar/(mol·K); a=3,592 L²·bar/mol² y b=0,04267 L/mol; presión bar. No mezclar estos coeficientes con R en J/(mol·K).
