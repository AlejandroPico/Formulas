# Regla de Cramer

Cada incógnita es un cociente de determinantes. Esta regla da una solución única cuando la matriz es invertible; no resuelve por división un sistema singular.

## Magnitudes

| Símbolo | Significado |
| :-- | :-- |
| A | Matriz cuadrada de coeficientes del sistema. |
| x | Vector de incógnitas; x_i es su componente i. |
| b | Vector de términos independientes. |
| det | Determinante de la matriz indicada. |
| i | Índice de columna o incógnita. |
| _A:i | Matriz A con la columna i sustituida por b. |

## Alcance

Matriz cuadrada y det(A)≠0. Un determinante muy pequeño puede amplificar errores aunque no sea exactamente cero.

## Unidades

El laboratorio usa números sin dimensión. En un sistema físico cada ecuación debe tener unidades compatibles; no se suman longitudes y fuerzas por el hecho de estar en una matriz. La unidad de x_i sale del cociente de determinantes correspondiente.
