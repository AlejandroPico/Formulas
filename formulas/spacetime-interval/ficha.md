# Intervalo espaciotemporal

Con firma −+++, una separación temporal tiene ds²<0, una espacial ds²>0 y la luz ds²=0. El boost cambia coordenadas y conserva esta clasificación.

## Magnitudes y notación

| Símbolo | Interpretación |
| :-- | :-- |
| c | Velocidad de la luz en vacío, 299 792 458 m/s. |
| β | Velocidad firmada del sistema móvil dividida por c. |
| γ | Factor de Lorentz 1/√(1−β²), siempre al menos uno. |
| x | Coordenada espacial del evento en el eje de movimiento. |
| t | Tiempo coordinado del evento en el sistema indicado. |
| v | Velocidad firmada del sistema S′ respecto de S. |
| τ | Tiempo propio acumulado por un reloj en su línea de universo. |
| Δ | Diferencia entre valores de dos eventos. |
| L | Longitud de la barra medida en el sistema donde se mueve. |
| s | Intervalo espaciotemporal firmado; s² puede ser negativo. |
| y | Coordenada espacial transversal y. |
| z | Coordenada espacial transversal z. |

## Condiciones

Espacio-tiempo plano y firma explícita −+++. El intervalo entre eventos finitos no sustituye la integral de tiempo propio de una trayectoria acelerada. Con separación espacial no se toma una raíz real para inventar tiempo propio.

## Unidades

ct,x,y,z en longitud y ds² en longitud². El laboratorio usa unidad L común y β adimensional; √(−ds²) tiene longitud y dividir por c da tiempo.
