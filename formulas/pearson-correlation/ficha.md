# Correlación de Pearson

Cinco datos controlables: y=pendiente·x+ruido·patrón+desplazamiento. Patrón de ruido ortogonal a x; población completa, divisor N=5.

## Magnitudes

| Símbolo | Significado |
| :-- | :-- |
| x | Variable observada x; xi dato indexado y μx media. |
| y | Variable observada y; yi dato indexado y μy media. |
| i | Índice de observación. |
| N | Número de observaciones de toda la población finita. |
| μ | Media poblacional de la variable indicada. |
| σ | Desviación típica poblacional; σxy covarianza. |
| r | Correlación lineal de Pearson. |

## Condiciones

Varianzas positivas y datos pareados. Si una variable es constante, r es indefinida. Solo mide asociación lineal; r=0 no implica independencia y r alto no demuestra causalidad.

## Unidades

Covarianza unidad x·unidad y; desviaciones en unidades propias y r adimensional. El ejemplo trata los cinco datos como población finita con divisor N=5; el estimador muestral usa otra convención consistente.
