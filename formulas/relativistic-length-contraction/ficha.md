# Contracción de longitudes

L0 es longitud en reposo. L se mide con eventos simultáneos en el sistema donde la barra se mueve; una fotografía mezcla tiempos de llegada de luz.

## Magnitudes y notación

| Símbolo | Interpretación |
| :-- | :-- |
| c | Velocidad de la luz en vacío, 299 792 458 m/s. |
| β | Velocidad firmada del sistema móvil dividida por c. |
| γ | Factor de Lorentz 1/√(1−β²), siempre al menos uno. |
| x | Coordenada espacial del evento en el eje de movimiento. |
| t | Tiempo coordinado del evento en el sistema indicado. |
| v | Velocidad firmada del sistema S′ respecto de S. |
| τ | Tiempo propio acumulado por un reloj en su línea de universo. |
| Δ | Diferencia entre valores de dos eventos. |
| L | Longitud de la barra medida en el sistema donde se mueve. |

## Condiciones

Barra rígida ideal con movimiento inercial colineal y |v|<c. L0 se mide en reposo. La contracción es de coordenadas medidas, no una deformación en el sistema propio; dimensiones transversales no cambian bajo este boost.

## Unidades

L,L0 en m; v m/s, c m/s; γ adimensional. Los dos trazos comparten escala espacial. En el diagrama de simultaneidad ct tiene unidad de longitud.
