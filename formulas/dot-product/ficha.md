# Producto escalar

El producto escalar mide cuánto coinciden dos vectores en dirección y magnitud. Puede ser positivo, negativo o cero. El ángulo necesita direcciones definidas; con un vector nulo el producto vale cero, pero el ángulo no existe.

## Magnitudes

| Símbolo | Significado |
| :-- | :-- |
| a | Primer vector; define la dirección de proyección cuando no es nulo. |
| b | Segundo vector, que se proyecta sobre a. |
| i | Índice de componente cartesiana ortonormal. |
| n | Dimensión del espacio; el laboratorio usa tres. |
| θ | Ángulo entre dos vectores no nulos, de 0 a π. |
| proj | Proyección vectorial ortogonal sobre la dirección indicada. |

## Alcance

Producto euclídeo en base cartesiana ortonormal. Ángulo requiere ambos vectores no nulos; proyección sobre a requiere a≠0. En coordenadas no ortonormales se debe incluir la métrica correspondiente.

## Unidades

Componentes geométricas en u y producto en u². La proyección tiene unidad u; cosθ es adimensional. Para fuerza N y desplazamiento m, el producto tiene N·m=J, sin que eso lo convierta en un vector.
