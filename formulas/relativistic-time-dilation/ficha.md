# Dilatación temporal

El tiempo propio une dos eventos en el mismo reloj. En el laboratorio móvil respecto del reloj, el intervalo coordinado es γ veces mayor.

## Magnitudes y notación

| Símbolo | Interpretación |
| :-- | :-- |
| c | Velocidad de la luz en vacío, 299 792 458 m/s. |
| β | Velocidad firmada del sistema móvil dividida por c. |
| γ | Factor de Lorentz 1/√(1−β²), siempre al menos uno. |
| x | Coordenada espacial del evento en el eje de movimiento. |
| t | Tiempo coordinado del evento en el sistema indicado. |
| v | Velocidad firmada del sistema S′ respecto de S. |
| τ | Tiempo propio acumulado por un reloj en su línea de universo. |
| Δ | Diferencia entre valores de dos eventos. |
| L | Longitud de la barra medida en el sistema donde se mueve. |

## Condiciones

Reloj en movimiento inercial uniforme para la relación de intervalos finitos. El diferencial puede integrarse a lo largo de una trayectoria, pero el laboratorio no simula el cambio de sistema de un viaje de ida y vuelta.

## Unidades

Δt,Δτ,t en s; β adimensional. En el dibujo un segundo-luz es c×1 s de longitud, y la separación entre espejos es 1 ls. Un ciclo propio completo tarda 2 s.
