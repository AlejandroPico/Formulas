# Ecuación de ondas unidimensional

La curvatura espacial y la aceleración temporal se relacionan en una señal que se propaga por un medio lineal.

## Magnitudes

| Símbolo | Lectura |
| :-- | :-- |
| u | Desplazamiento transversal o campo ondulatorio dependiente de posición y tiempo. |
| t | Tiempo. |
| x | Posición fija a lo largo del medio. |
| c | Rapidez positiva de propagación de la señal. |
| A | Amplitud máxima de la onda representada. |
| k | Número de onda angular: 2π/λ. |
| ω | Frecuencia angular: ck, en rad/s. |
| λ | Longitud de onda: distancia entre puntos de fase equivalente. |

## Cuándo se aplica

Medio lineal uniforme, rapidez constante y ausencia de disipación; para una cuerda, pequeñas pendientes. Las ondas se superponen bajo esas hipótesis.

## Evita estos errores

Mover la partícula con la cresta; confundir ω con f; usar c como velocidad vertical; presentar una onda estacionaria como ausencia de movimiento del medio.

## Laboratorio

**Señales · Explorar · Interferencia**

Reproduce una onda viajera. La marca azul es un punto fijo del medio: sube y baja sin viajar con la cresta.

Compara una onda viajera con una onda estacionaria, resultado de dos ondas opuestas de igual amplitud A/2.
