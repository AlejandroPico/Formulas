# Fórmula del binomio de Newton

Construye potencias con elecciones combinatorias, términos positivos o negativos y el triángulo de Pascal.

## Magnitudes

| Símbolo | Lectura |
| :-- | :-- |
| a, b | Términos del binomio; el producto debe ser conmutativo. |
| n | Entero no negativo. |
| k | Entero entre 0 y n. |
| C(n,k) | Número de elecciones de k posiciones entre n. |

## Cuándo se aplica

Expansión finita para n entero no negativo y cantidades conmutativas. El laboratorio limita n a 10 para mostrar los términos. La extensión a exponentes no enteros requiere una serie y condiciones de convergencia.

## Evita estos errores

Omitir extremos; usar n no entero en la suma finita; perder signos de b; confundir factorial con potencia; aplicar la identidad a matrices que no conmutan.

## Laboratorio

**Combinaciones · Explorar · Pascal**

Cada barra es un término con su signo. El exponente n es entero; para n = 0 la suma contiene un único término uno.

Cuatro misiones con pistas y reintentos. Los controles aceptan teclado; los objetos arrastrables aceptan ratón y tacto. Los resultados se ocultan mientras resuelves un reto.
