# Aprendizaje

## Predice, juega y explica

Una corriente constante carga placas circulares ideales. La corriente de desplazamiento hace consistente el campo magnético calculado entre placas o sobre el conductor.

**Corriente · Campo 3D · Perfil magnético**

Elige entre misiones guiadas, exploración libre y la tercera vista que conecta el dibujo con otra representación. Puedes repetir, pedir una pista y cambiar tu respuesta.

## Cuatro misiones

1. **Predice el experimento.** Encuentra B en un lazo entre las placas. Con los valores iniciales, calcula campo magnético en µT.

2. **Construye una solución.** Ajusta corriente de carga para conseguir campo magnético = 3,2 µT.

3. **Elige con criterio.** ¿Cuál de estas afirmaciones describe correctamente este experimento?

4. **Comprueba otro escenario.** Cambia el escenario a Corriente de carga=2. Calcula campo magnético en µT.

## La explicación importa

Con flujo eléctrico uniforme, Id encerrada=I·min(r²/R²,1); B=μ0Id/(2πr). Se ignoran bordes.

Antes de mover el control, predice el sentido del cambio. Comprueba números y unidades; explica qué hipótesis hace posible el resultado. Vacío, placas ideales, variación cuasiestática y campo uniforme entre ellas; se ignoran bordes. El lazo del laboratorio se encuentra entre placas, donde I de conducción es cero.
