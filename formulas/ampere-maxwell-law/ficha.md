# Ley de Ampère-Maxwell

Una corriente constante carga placas circulares ideales. La corriente de desplazamiento hace consistente el campo magnético calculado entre placas o sobre el conductor.

## Magnitudes

| Símbolo | Significado |
| :-- | :-- |
| B | Campo magnético. |
| C | Lazo cerrado orientado de integración. |
| ℓ | Elemento de línea tangente al lazo. |
| μ | Permeabilidad del vacío en μ0. |
| ε | Permitividad del vacío en ε0. |
| I | Corriente de conducción encerrada; Id corriente de desplazamiento. |
| Φ | Flujo eléctrico a través de la superficie. |
| E | Campo eléctrico; índice E identifica su flujo. |
| t | Tiempo físico. |
| d | Índice d: desplazamiento en Id; diferencial en integrales. |
| r | Radio del lazo circular. |
| π | Pi, constante geométrica. |

## Condiciones

Vacío, placas ideales, variación cuasiestática y campo uniforme entre ellas; se ignoran bordes. El lazo del laboratorio se encuentra entre placas, donde I de conducción es cero.

## Unidades

I,Id A; B T, mostrado µT; radio cm convertido a m. ΦE V·m; ε0 dΦE/dt A. No representar la corriente de desplazamiento como electrones atravesando el vacío.
