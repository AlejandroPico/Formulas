# Unidades

Si x tiene unidad X y f unidad Y, f^(n) tiene Y/Xⁿ y el factor (x−a)ⁿ devuelve Y a cada término. El factorial es adimensional. Las funciones exp, sin y ln del laboratorio usan argumentos adimensionales; el seno usa radianes. El error firmado comparte la unidad de f. Una cota es una magnitud no negativa, aunque el error firmado pueda cambiar de signo. Centro y punto evaluado deben usar la misma unidad.

## Comprobación dimensional

Antes de calcular, escribe la unidad de cada entrada y conviértela a las unidades de la expresión. Una igualdad numérica con unidades incompatibles no valida un resultado.
