# Segunda ley de Newton

La fuerza neta determina el cambio de cantidad de movimiento; con masa constante, determina la aceleración.

## Magnitudes

| Símbolo | Lectura |
| :-- | :-- |
| F | Cada fuerza externa aplicada; el sumatorio forma la fuerza neta. |
| p | Vector cantidad de movimiento. |
| m | Masa constante del cuerpo. |
| a | Vector aceleración: cambio de velocidad por unidad de tiempo. |
| v | Vector velocidad. |
| t | Tiempo desde el estado inicial. |

## Cuándo se aplica

Marco inercial, masa positiva constante y velocidades clásicas. La fórmula integrada del laboratorio requiere fuerza neta constante durante todo el intervalo.

## Evita estos errores

Confundir fuerza aplicada con fuerza neta; concluir reposo cuando a=0; igualar dirección de F y v; usar F=ma sin declarar la constancia de masa.

## Laboratorio

**Rutas · Explorar · Trayectoria**

Cambia una fuerza neta constante y sigue la trayectoria de una nave con velocidad inicial horizontal.

La fuerza fija la aceleración. La velocidad puede apuntar en otra dirección; fuerza nula conserva la velocidad inicial.
