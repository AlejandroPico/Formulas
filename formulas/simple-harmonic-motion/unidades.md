# Unidades

| Magnitud | Unidad SI |
| :-- | :-- |
| x, A | m |
| t, T | s |
| v | m/s |
| a | m/s² |
| k | N/m = kg/s² |
| m | kg |
| ω | rad/s |
| φ | rad |
| E, U, K | J |

ωt y φ deben compartir unidad angular. El control de fase se muestra en grados y se convierte a radianes. La frecuencia en hercios es f = ω/(2π), distinta del número ω. k/m tiene unidad s⁻², así que su raíz tiene unidad s⁻¹.
