# Teorema de Cayley-Hamilton

Toda matriz cuadrada satisface su polinomio característico. Verifica A²−tr(A)A+det(A)I término a término, incluyendo matrices no diagonalizables.

## Magnitudes

| Símbolo | Significado |
| :-- | :-- |
| p | Polinomio característico de la matriz indicada. |
| A | Matriz cuadrada; en el laboratorio matriz real 2×2. |
| λ | Variable escalar del polinomio característico. |
| I | Matriz identidad de tamaño compatible. |
| det | Determinante de la matriz. |
| tr | Traza, suma de entradas diagonales. |
| ℝ | Conjunto de números reales. |

## Condiciones

Matriz cuadrada sobre reales o complejos; el término constante se multiplica por I. No requiere simetría ni diagonalización. Cero en pA(A)=0 es matriz cero, no solo determinante cero.

## Unidades

Entradas adimensionales en el experimento. Si A tiene unidades, el coeficiente de cada potencia debe compatibilizar unidades matriciales; λ debe tener la misma unidad espectral.
