# Ley de Poiseuille

El caudal laminar de un tubo circular depende de la cuarta potencia del radio. Una pequeña modificación geométrica puede dominar el resultado, pero solo si el flujo sigue cumpliendo las hipótesis del modelo.

## Magnitudes

| Símbolo | Significado |
| :-- | :-- |
| Q | Caudal volumétrico a través del tubo. |
| p | Presión; Δp es presión de entrada menos salida. |
| R | Radio interior del tubo circular. |
| μ | Viscosidad dinámica positiva del fluido newtoniano. |
| L | Longitud axial del tramo plenamente desarrollado. |
| u | Velocidad axial local; la barra superior indica su media sobre la sección. |
| r | Distancia radial desde el eje, entre 0 y R. |
| ρ | Densidad del fluido; el ejemplo fija 1000 kg/m³. |
| Re | Número de Reynolds basado en diámetro y velocidad media. |

## Alcance

Tubo recto circular, fluido newtoniano incompresible, régimen estacionario laminar, no deslizamiento y perfil plenamente desarrollado. Para Re del orden de transición o superior no se valida la predicción como flujo real.

## Unidades

R del control en mm se divide entre 1000; μ en mPa·s también. Δp Pa, L m y Q m³/s; multiplicar por 10⁶ da mL/s. Densidad kg/m³; Re adimensional. La vista 3D usa radio normalizado y flechas relativas.
