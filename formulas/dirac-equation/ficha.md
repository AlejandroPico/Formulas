# Ecuación de Dirac

Reducción libre 1+1 con H=pσx+mσz y ħ=c=1. Compara energía positiva, estado espinorial y velocidad de grupo; no modela creación de pares.

## Magnitudes y notación

| Símbolo | Interpretación |
| :-- | :-- |
| ħ | Constante de Planck reducida h/(2π). |
| i | Unidad imaginaria: i²=−1. |
| H | Hamiltoniano, operador de energía. |
| E | Energía del estado o autovalor especificado. |
| t | Tiempo físico o tiempo reducido según las unidades del laboratorio. |
| x | Coordenada espacial; en la caja pertenece al intervalo entre paredes. |
| p | Impulso lineal del observable o partícula indicado. |
| m | Masa de la partícula. |
| σ | Matriz de Pauli con el índice de eje indicado; σ como anchura se especifica en la ficha. |
| Ψ | Espinor de Dirac; dos componentes en la reducción 1+1. |
| α | Matrices de Dirac que acoplan componentes del impulso. |
| β | Matriz de Dirac del término de masa; no velocidad dividida por c. |
| c | Velocidad de la luz en vacío. |
| ± | Dos ramas de energía, positiva y negativa. |
| ∂ | Derivada parcial temporal. |

## Condiciones

Campo libre relativista. La figura resuelve una reducción 1+1 de dos componentes, no el espinor completo 3+1. No simula creación de pares, campos externos ni un proceso de antipartículas. Masa del control positiva para evitar el punto E=0 degenerado.

## Unidades

Ecuación SI: H J, p kg·m/s, m kg. En la reducción ħ=c=1: p,m,E en Eref; longitud ħc/Eref, tiempo ħ/Eref y velocidad dividida por c.
