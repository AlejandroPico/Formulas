# Farmacocinética de un compartimento

Cantidad inicial hipotética distribuida en un compartimento homogéneo, tras un bolo instantáneo. Eliminación lineal y volumen constante; el laboratorio no diseña dosis clínicas.

## Magnitudes y notación

| Símbolo | Interpretación |
| :-- | :-- |
| M | Cantidad de sustancia en el compartimento. |
| C | Concentración M/V; en CL, C forma parte de la abreviatura aclaramiento. |
| L | Parte de CL: aclaramiento, volumen retirado efectivamente por tiempo. |
| V | Volumen aparente de distribución. |
| k | Constante de eliminación CL/V. |
| t | Tiempo desde el bolo instantáneo hipotético. |
| A | Parte de AUC: área bajo la curva de concentración. |
| U | Parte de AUC: área bajo la curva. |
| d | Diferencial temporal para expresar tasa. |
| ∞ | Límite de tiempo infinito en el área total. |
| → | Desde cero hasta tiempo infinito. |

## Condiciones

Bolo instantáneo hipotético, un compartimento, eliminación lineal, CL y V positivos y constantes. Sin absorción, metabolismo saturable, tejidos separados ni dosificación repetida. V es volumen aparente de distribución y no debe confundirse necesariamente con un volumen anatómico. No se calibra con datos clínicos ni recomienda cantidades.

## Unidades

M0 en mg, V en L, CL en L/h, k en h⁻¹ y C en mg/L. AUC en mg·h/L. La cantidad es de ejemplo; el tiempo es hora física y el simulador no usa un reloj acelerado. Cambiar V altera C0 y la semivida, mientras la AUC permanece fijada por M0 y CL.
