# Ley de Gauss eléctrica

El flujo eléctrico neto depende de la carga encerrada, no de todas las cargas que generan campo en la superficie. Una carga exterior puede crear campo intenso y aun así producir igual flujo entrante y saliente.

## Magnitudes

| Símbolo | Significado |
| :-- | :-- |
| 0 | Subíndice de permitividad del vacío. |
| E | Campo eléctrico vectorial en la posición de la superficie. |
| n | Normal exterior unitaria de la superficie cerrada. |
| S | Superficie cerrada orientada que delimita un interior. |
| A | Área; dA es un elemento de superficie. |
| Q | Carga total encerrada por la superficie. |
| enc | Subíndice de encerrada: solo las cargas interiores contribuyen al flujo neto. |
| ε | ε_0 es la permitividad del vacío. |
| q | Carga puntual fuente, con signo. |
| r | Vector de posición; r_q es la posición de la carga fuente. |

## Alcance

Superficie cerrada con normal exterior. Una carga puntual sobre el borde hace singular el campo: el laboratorio señala ese caso y no asigna una carga encerrada arbitraria. Vacío, electrostática puntual y principio de superposición.

## Unidades

q,Q en C; el control usa nC y se multiplica por 10⁻⁹. ε0 en C²/(N·m²), campo N/C y flujo N·m²/C. Las flechas del dibujo se normalizan con una escala común por imagen; el flujo usa valores físicos.
