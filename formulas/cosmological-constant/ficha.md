# Constante cosmológica

Caso exacto plano de vacío puro con Λ>0. H es constante y a crece exponencialmente; densidad equivalente del vacío permanece constante, con presión negativa.

## Magnitudes y notación

| Símbolo | Interpretación |
| :-- | :-- |
| G | Constante de gravitación de Newton; G con índices es el tensor de Einstein. |
| g | Tensor métrico que define intervalos y firma −+++. |
| μ | Índice de coordenada de espacio-tiempo, de cero a tres. |
| ν | Segundo índice tensorial de espacio-tiempo. |
| R | Curvatura escalar; R con índices es tensor de Ricci. |
| T | Tensor de energía-momento con índices; t minúscula es tiempo. |
| κ | Acoplamiento gravitatorio 8πG/c⁴. |
| Λ | Constante cosmológica, unidad m⁻². |
| c | Velocidad de la luz en vacío, 299 792 458 m/s. |
| H | Parámetro de Hubble, H=ȧ/a. |
| a | Factor de escala adimensional de una solución homogénea. |
| ρ | Densidad equivalente de masa, energía volumétrica dividida entre c². |
| p | Presión del fluido. |
| w | Razón adimensional p/(ρc²). |
| t | Tiempo cósmico propio de observadores comóviles. |
| π | Pi: constante del acoplamiento. |
| r | Radio físico del horizonte cosmológico de de Sitter. |
| e | Número de Euler: base del crecimiento exponencial. |

## Condiciones

Λ positiva y constante para el caso de de Sitter del simulador; la ecuación general admite otros signos y fuentes. Modelo homogéneo plano sin materia ordinaria. ρΛ no se diluye con a; presión negativa no equivale a energía negativa. No afirma que la expansión real sea vacío puro.

## Unidades

Λ m⁻², control en 10⁻⁵² m⁻². ρΛ kg/m³, pΛ Pa. H calculado s⁻¹ y mostrado km/s/Mpc. t físico Gyr y rH Gly: un Gly es c×un Gyr. a adimensional; 1 s visual equivale a 1 Gyr.
