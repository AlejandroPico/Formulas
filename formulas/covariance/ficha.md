# Covarianza

Cinco datos controlables: y=pendiente·x+ruido·patrón+desplazamiento. Patrón de ruido ortogonal a x; población completa, divisor N=5.

## Magnitudes

| Símbolo | Significado |
| :-- | :-- |
| x | Variable observada x; xi dato indexado y μx media. |
| y | Variable observada y; yi dato indexado y μy media. |
| i | Índice de observación. |
| N | Número de observaciones de toda la población finita. |
| μ | Media poblacional de la variable indicada. |
| σ | Desviación típica poblacional; σxy covarianza. |
| r | Correlación lineal de Pearson. |
| s | Covarianza muestral insesgada sxy bajo muestreo apropiado. |
| n | Tamaño de la muestra. |

## Condiciones

Pares comparables y segundos momentos finitos. No es correlación normalizada ni un indicador causal; puede ser cero en relaciones no lineales fuertes.

## Unidades

Unidad x multiplicada por unidad y. Ejemplo N=5 como población; usa divisor 5. La segunda expresión documenta el estimador muestral con n−1, sin mezclarlo con los números del simulador.
