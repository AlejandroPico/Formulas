# Historia

Cobb y Douglas popularizaron una función de producción con elasticidades simples para estudiar capital y trabajo. El uso empírico depende de medición y supuestos. La forma matemática ofrece una herramienta para separar escalado conjunto y contribución marginal, sin afirmar una ley universal de toda actividad productiva.
