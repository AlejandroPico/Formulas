# Operador Hamiltoniano

El Hamiltoniano cuántico es un operador, no solo un número de energía clásica. En el pozo infinito sus estados propios tienen energías discretas; una superposición cambia su densidad por interferencia mientras conserva la energía esperada.

## Magnitudes

| Símbolo | Significado |
| :-- | :-- |
| H | Operador Hamiltoniano cuántico de energía; actúa sobre la función de onda. |
| m | Masa de la partícula. |
| x | Posición dentro de un pozo unidimensional. |
| V | Energía potencial como función de posición; cero dentro y barrera infinita fuera del pozo. |
| ψ | Función de onda; ψ_n es un estado propio normalizado de energía. |
| E | Autovalor de energía del nivel indicado. |
| n | Índice entero positivo del estado, no número de partículas. |
| L | Longitud del pozo infinito entre x=0 y x=L. |
| ℏ | Constante de Planck reducida, que fija las escalas de acción. |

## Alcance

Pozo infinito ideal 1D, masa constante y paredes Dirichlet. Solo se mezclan dos estados ortonormales n y n+1. El experimento usa ℏ=m=1 en unidades reducidas; no afirma representar energías de un material real.

## Unidades

Elige longitud uℓ; uE=ℏ²/(m uℓ²) y uτ=ℏ/uE. ψ usa uℓ⁻¹/² y |ψ|² uℓ⁻¹. La integral de densidad es adimensional y vale uno. No se etiquetan estas energías reducidas como eV.
