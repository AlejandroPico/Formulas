# Potencial de hidrógeno (pH)

El pH usa la actividad adimensional del ion hidrógeno, no el logaritmo de una cantidad con unidad. La concentración es una aproximación en soluciones suficientemente ideales.

## Magnitudes y notación

| Símbolo | Interpretación |
| :-- | :-- |
| pH | pH: logaritmo decimal negativo de actividad del ion hidrógeno. |
| p | Prefijo p: aplica el logaritmo decimal negativo. |
| H | Hidrógeno; H+ representa el ion hidrógeno acuoso, abreviatura de hidronio. |
| a | Actividad adimensional del ion respecto del estado estándar. |
| γ | Coeficiente de actividad del ion hidrógeno. |
| c | Concentración estándar c° que hace adimensional el cociente. |
| log | Logaritmo decimal cuando lleva subíndice 10. |
| ∘ | Marca de estado estándar, no grados de temperatura. |

## Condiciones

Actividad positiva y estándar especificado. Un pH negativo o mayor que catorce no es una contradicción. Actividades de iones individuales tienen una definición operacional y convenciones de medida; no se deducen exactamente de una concentración sin coeficientes.

## Unidades

aH,γH adimensionales; [H+] y c° en la misma unidad molar; pH adimensional. El control usa log10 aH entre −16 y 1; no se interpreta como concentración clínica de una muestra real.
