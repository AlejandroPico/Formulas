# Ley de Stefan-Boltzmann

Distingue emisión de intercambio neto. Una superficie gris en entorno uniforme puede ganar radiación si está más fría; temperaturas en kelvin.

## Magnitudes

| Símbolo | Significado |
| :-- | :-- |
| j | Potencia emitida por unidad de superficie de cuerpo negro. |
| σ | Constante de Stefan–Boltzmann. |
| T | Temperatura absoluta superficial; Ta temperatura del entorno. |
| P | Potencia radiativa; Pe emitida y Pn neta saliente. |
| ε | Emisividad gris de la superficie, entre 0 y 1. |
| A | Área radiativa. |
| e | Índice e: emitida. |
| n | Índice n: neta. |
| a | Índice a: ambiente térmico uniforme. |

## Condiciones

Superficie gris, temperaturas uniformes y entorno que llena la vista para la expresión neta. No calcula convección, conducción ni factores de vista entre cuerpos arbitrarios.

## Unidades

σ W/(m²·K⁴), A m², T K dan P W. Emisividad adimensional. No elevar grados Celsius a la cuarta potencia ni confundir j W/m² con potencia total.
