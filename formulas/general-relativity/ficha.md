# Relatividad general de Einstein

Caso exacto FLRW plano con polvo y Λ=0. La expansión diluye materia y H cambia; no es un solucionador de cualquier distribución gravitatoria.

## Magnitudes y notación

| Símbolo | Interpretación |
| :-- | :-- |
| G | Constante de gravitación de Newton; G con índices es el tensor de Einstein. |
| g | Tensor métrico que define intervalos y firma −+++. |
| μ | Índice de coordenada de espacio-tiempo, de cero a tres. |
| ν | Segundo índice tensorial de espacio-tiempo. |
| R | Curvatura escalar; R con índices es tensor de Ricci. |
| T | Tensor de energía-momento con índices; t minúscula es tiempo. |
| κ | Acoplamiento gravitatorio 8πG/c⁴. |
| Λ | Constante cosmológica, unidad m⁻². |
| c | Velocidad de la luz en vacío, 299 792 458 m/s. |
| H | Parámetro de Hubble, H=ȧ/a. |
| a | Factor de escala adimensional de una solución homogénea. |
| ρ | Densidad equivalente de masa, energía volumétrica dividida entre c². |
| p | Presión del fluido. |
| w | Razón adimensional p/(ρc²). |
| t | Tiempo cósmico propio de observadores comóviles. |
| π | Pi, constante numérica del acoplamiento gravitatorio. |

## Condiciones

Teoría general: deben especificarse fuente, coordenadas y condiciones. Experimento: FLRW plano, homogéneo e isótropo, polvo p=0, Λ=0, solución en expansión. No modela agujeros negros ni galaxias individuales; una nube de puntos comóviles visualiza separación física.

## Unidades

Gμν,Rμν,R,Λ m⁻² con coordenada temporal ct; T00 energía por volumen. κ=8πG/c⁴ hace κT compatible. Control ρ0 en 10⁻²⁶ kg/m³; t visual en Gyr físicos (1 s de reproducción=1 Gyr); H se presenta en km/s/Mpc.
