# Regla de conmutación canónica

Representación de ocho estados de Fock. En el interior reproduce [a,a†]=1; el estado superior revela por qué matrices finitas no pueden satisfacer [x,p]=iħI exactamente.

## Magnitudes y notación

| Símbolo | Interpretación |
| :-- | :-- |
| ħ | Constante de Planck reducida h/(2π). |
| i | Unidad imaginaria: i²=−1. |
| x | Coordenada espacial; en la caja pertenece al intervalo entre paredes. |
| p | Impulso lineal del observable o partícula indicado. |
| n | Número cuántico entero que identifica el nivel. |
| I | Operador identidad. |
| a | Operador de destrucción del oscilador. |
| N | Dimensión del corte de Fock en el experimento finito. |
| † | Adjunto hermítico del operador de destrucción. |
| [ | Inicio del conmutador AB−BA. |
| ] | Fin del conmutador. |
| ∣ | Marca de ket o bra en un proyector de estado. |
| ⟩ | Cierre de ket. |
| ⟨ | Inicio de bra: dual hermítico de un ket. |
| ∑ | Sumatorio de transiciones dentro del corte finito. |

## Condiciones

La identidad canónica exacta pertenece al espacio infinito y a dominios operatoriales adecuados. El corte finito es una aproximación: no debe presentarse como demostración de la identidad sin la corrección de borde. Tampoco refuta la mecánica cuántica.

## Unidades

[x,p] tiene unidad de acción J·s, igual a ħ. El conmutador de escalera y el experimento finito son adimensionales. N=8 es dimensión, no número de partículas del baño.
