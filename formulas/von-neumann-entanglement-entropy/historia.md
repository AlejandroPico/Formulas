# Historia

La formulación de von Neumann permite comparar información local y global. En un estado entrelazado puro, conocer perfectamente el estado conjunto es compatible con una matriz local mixta; esa distinción no se reduce a desconocer una etiqueta clásica de cada subsistema.

Familia bipartita pura de dos qubits en forma de Schmidt. La entropía reducida no es por sí sola una medida de entrelazamiento de un estado global mixto. Las correlaciones no permiten enviar mensajes instantáneos cambiando una base local.
