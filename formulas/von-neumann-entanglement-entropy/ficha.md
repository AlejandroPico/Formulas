# Entrelazamiento y entropía de von Neumann

Estado puro √p|00⟩+√(1−p)|11⟩. El sistema total tiene entropía cero, pero cada qubit reducido puede tener entropía positiva.

## Magnitudes y notación

| Símbolo | Interpretación |
| :-- | :-- |
| ρ | Operador densidad hermítico, positivo y de traza uno. |
| p | Peso de Schmidt de ∣00⟩. |
| S | Entropía del estado; cuando lleva argumento de un camino designa su acción. |
| Ψ | Estado global puro de los dos qubits. |
| A | Subsistema A; no una matriz arbitraria aquí. |
| B | Subsistema B sobre el que se toma la traza parcial. |
| Tr | Traza o traza parcial indicada por su índice. |
| log | Logaritmo en base dos indicado en la expresión. |
| ∣ | Marca de ket o bra en un proyector cuántico. |
| ⟩ | Cierre de ket. |
| ⟨ | Inicio de bra. |

## Condiciones

Familia bipartita pura de dos qubits en forma de Schmidt. La entropía reducida no es por sí sola una medida de entrelazamiento de un estado global mixto. Las correlaciones no permiten enviar mensajes instantáneos cambiando una base local.

## Unidades

p y matrices densidad adimensionales. Entropía en bits por usar base dos; con logaritmo natural sería en nats. Se adopta el límite 0log0=0 en los extremos.
