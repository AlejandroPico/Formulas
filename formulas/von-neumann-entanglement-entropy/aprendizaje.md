# Aprendizaje

## Tres formas de aprender

**Pares correlacionados · Explorar · Estado reducido**

Estado puro √p|00⟩+√(1−p)|11⟩. El sistema total tiene entropía cero, pero cada qubit reducido puede tener entropía positiva.

## Predice, prueba y justifica

1. **Predice antes de medir.** Estado puro √p|00⟩+√(1−p)|11⟩. El sistema total tiene entropía cero, pero cada qubit reducido puede tener entropía positiva. Calcula entropía reducida con los datos iniciales en bits.

2. **Construye el objetivo.** Ajusta peso del par |00⟩ hasta obtener entropía reducida=1 bits.

3. **Distingue el modelo.** ¿Qué interpretación es correcta?

4. **Comprueba una nueva predicción.** Ahora peso del par |00⟩=0.5 . Calcula entropía reducida en bits y explica el cambio.

Los retos admiten pistas y reintentos. En exploración, mueve un control cada vez, anticipa el cambio y compara el resultado. Las vistas 3D admiten ratón, tacto y flechas del teclado.

## Una idea que debes poder explicar

Para el estado total puro, S(A) mide entrelazamiento con B

Familia bipartita pura de dos qubits en forma de Schmidt. La entropía reducida no es por sí sola una medida de entrelazamiento de un estado global mixto. Las correlaciones no permiten enviar mensajes instantáneos cambiando una base local.
