# Unidades

p y matrices densidad adimensionales. Entropía en bits por usar base dos; con logaritmo natural sería en nats. Se adopta el límite 0log0=0 en los extremos.

## Qué se convierte en el laboratorio

S(A)=−p log2 p−(1−p)log2(1−p), usando 0log0=0.

## Dominio y coherencia

Familia bipartita pura de dos qubits en forma de Schmidt. La entropía reducida no es por sí sola una medida de entrelazamiento de un estado global mixto. Las correlaciones no permiten enviar mensajes instantáneos cambiando una base local.

Estado puro √p|00⟩+√(1−p)|11⟩. El sistema total tiene entropía cero, pero cada qubit reducido puede tener entropía positiva.
