# Entropía diferencial

Entropía diferencial de una normal con desviación σ en una coordenada de referencia. Puede ser negativa y cambia bajo reescala; no equivale a bits de un símbolo discreto.

## Magnitudes y notación

| Símbolo | Interpretación |
| :-- | :-- |
| h | Entropía diferencial respecto a la coordenada de referencia. |
| X | Variable aleatoria continua. |
| f | Densidad de probabilidad en la coordenada x. |
| x | Coordenada continua fijada. |
| d | Diferencial de integración en x. |
| N | Familia de distribución normal cuando aparece como N caligráfica. |
| μ | Media de la normal. |
| σ | Desviación positiva de la normal. |
| a | Factor de reescala no nulo. |
| ∣ | Módulo del factor de reescala. |

## Condiciones

Densidad normal con σ positiva, y referencia de coordenada explícita. No se toma el logaritmo de una densidad dimensional sin reconocer esa referencia. La entropía diferencial no es la entropía de un registro cuantizado: fijar resolución añade información sobre discretización. Una traslación de media no cambia h.

## Unidades

x y σ se expresan en la unidad de coordenada escogida; f integra uno y tiene unidad inversa de coordenada. h se informa en bits respecto a esa escala. Cambiar de unidad por un factor de 100 añade log2(100) en la representación correspondiente, sin cambiar el fenómeno físico.
