# Equilibrio químico dinámico

Solución exacta de A⇌B con cinéticas de primer orden. La suma se conserva y en equilibrio las velocidades opuestas son iguales y generalmente no nulas.

## Magnitudes

| Símbolo | Significado |
| :-- | :-- |
| A | Concentración de especie A cuando va entre corchetes. |
| B | Concentración de especie B cuando va entre corchetes. |
| k | Constante cinética del sentido indicado. |
| f | Índice f: reacción directa. |
| r | Índice r: reacción inversa. |
| C | Concentración total conservada. |
| t | Tiempo desde la mezcla inicial. |
| e | Índice e: equilibrio. |

## Condiciones

Sistema cerrado homogéneo de volumen y temperatura constantes; cinéticas de primer orden en ambos sentidos y constantes positivas. Modelo elemental específico, no cualquier reacción reversible.

## Unidades

[A],[B],C mol/L; kf,kr s⁻¹ y t s. Velocidades mol/(L·s). K=kf/kr adimensional para esta estequiometría.
