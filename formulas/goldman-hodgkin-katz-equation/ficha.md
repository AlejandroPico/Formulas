# Ecuación de Goldman-Hodgkin-Katz (GHK)

Potencial de membrana a corriente iónica neta nula, bajo campo constante, con K+,Na+,Cl−. Concentraciones positivas hipotéticas y temperatura absoluta.

## Magnitudes y notación

| Símbolo | Interpretación |
| :-- | :-- |
| V | Potencial de membrana interior menos exterior. |
| m | Índice m: membrana. |
| R | Constante universal de los gases. |
| T | Temperatura absoluta kelvin. |
| F | Constante de Faraday, carga por mol de cargas elementales. |
| P | Permeabilidad de la especie indicada. |
| K | Potasio, ion monovalente K+. |
| N | Parte de Na: sodio monovalente. |
| a | Parte de Na: sodio monovalente. |
| C | Parte de Cl: cloruro monovalente negativo. |
| l | Parte de Cl: cloruro monovalente negativo. |
| [ | Abre la concentración de la especie química. |
| ] | Cierra la especie cuya concentración se usa. |
| + | Carga positiva si acompaña a K o Na; suma si une contribuciones. |
| − | Carga negativa en Cl−. |

## Condiciones

Iones monovalentes K+,Na+,Cl−, campo constante, permeabilidades constantes y corriente neta nula. V se define interior menos exterior. No asumir una corriente de cada especie igual a cero ni equilibrio químico completo. Concentraciones ficticias positivas, misma escala a ambos lados; se omiten bombas, valencias múltiples y dinámica de compuertas.

## Unidades

R en J/(mol·K), T en K y F en C/mol: RT/F produce voltios. El laboratorio convierte a mV y utiliza mM para todas las concentraciones; la razón es adimensional. PNa y PCl se introducen relativas a PK=1, no como conductancias eléctricas.
