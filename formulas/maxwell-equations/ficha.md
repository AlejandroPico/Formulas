# Ecuaciones de Maxwell

Onda plana de vacío: E en y, B en z y propagación en +x. E/B=c; el reloj visual representa fase, con periodo 5 s y tiempo físico equivalente tλ/(5c).

## Magnitudes

| Símbolo | Significado |
| :-- | :-- |
| E | Campo eléctrico de la onda. |
| B | Campo magnético de la onda. |
| c | Rapidez física de propagación en vacío. |
| μ | Permeabilidad del vacío en μ0. |
| ε | Permitividad del vacío en ε0. |
| t | Tiempo físico en la ecuación; reloj visual con conversión de fase en el laboratorio. |
| x | Coordenada de propagación. |
| y | Dirección transversal eléctrica. |
| z | Dirección transversal magnética. |
| k | Número de onda angular. |
| ω | Frecuencia angular física. |
| λ | Longitud de onda. |
| ρ | Densidad de carga eléctrica. |
| J | Densidad de corriente de conducción. |
| S | Vector de flujo de energía electromagnética. |
| π | Pi, constante de una vuelta de fase. |
| Z | Impedancia característica del vacío en Z0. |

## Condiciones

Forma microscópica SI en vacío con cargas y corrientes. En materiales se pueden reorganizar con D,H y relaciones constitutivas; no sustituir sin más ε0 por una respuesta arbitraria.

## Unidades

ρ C/m³, J A/m², E V/m, B T. Derivadas temporales son físicas. El laboratorio ralentiza la fase, con periodo visual 5 s; muestra E/E0 y cB/E0, no igualdad dimensional E=B.
