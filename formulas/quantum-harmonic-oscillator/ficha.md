# Oscilador armónico cuántico

Estado estacionario n de un oscilador 1D. Su densidad es |ψn|²; el nivel fundamental tiene energía de punto cero y no sigue una órbita clásica.

## Magnitudes y notación

| Símbolo | Interpretación |
| :-- | :-- |
| ψ | Función de onda compleja normalizada; su módulo al cuadrado da densidad de probabilidad. |
| ħ | Constante de Planck reducida h/(2π). |
| H | Hamiltoniano, operador de energía. |
| E | Energía del estado o autovalor especificado. |
| x | Coordenada espacial; en la caja pertenece al intervalo entre paredes. |
| p | Impulso lineal del observable o partícula indicado. |
| m | Masa de la partícula. |
| n | Número cuántico entero que identifica el nivel. |
| ω | Frecuencia angular firmada del Hamiltoniano o positiva del modo indicado. |
| ξ | Coordenada adimensional x√(mω/ħ). |
| ! | Factorial del entero n, producto de 1 a n. |
| H con índice | Polinomio de Hermite Hn, no el Hamiltoniano. |
| π | Pi, constante de normalización. |

## Condiciones

Potencial exactamente cuadrático, m>0, ω>0 y estado estacionario. Los niveles no representan posiciones ni trayectorias. La comparación con puntos de retorno es una referencia clásica, no una barrera dura del estado cuántico.

## Unidades

Energía ħωref, longitud √(ħ/mωref), tiempo 1/ωref. El control ω es ω/ωref y el código usa ħ=m=1 en esas unidades. La densidad tiene unidad inversa de longitud reducida.
