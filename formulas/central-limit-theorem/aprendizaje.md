# Aprendizaje

## Primero predice

Las sumas estandarizadas de variables independientes de igual distribución y varianza finita tienden a una normal. El tamaño necesario para una buena aproximación depende de la distribución, no de una regla universal de treinta datos.

Suma exacta de n ensayos Bernoulli independientes con probabilidad p. Las barras estandarizadas tienen área total uno; la normal es una aproximación y falla especialmente cuando np o n(1−p) son pequeños.

## Tres formas de aprender

**Promedios · Explorar · Aproximación normal**

Comprender error estándar, aproximación de conteos y efecto de tamaño de muestra. Si p está cerca de cero o uno, examina np y n(1−p) antes de aceptar una aproximación; la distribución original de un ensayo no se vuelve normal.

## Cuatro misiones

1. **Predice el resultado.** 4 ensayos independientes con p=0,5. ¿Cuántos éxitos se esperan?

2. **Diseña una solución.** Aumenta n hasta que el error estándar de la media sea 0,125.

3. **Piensa antes de cambiar.** ¿Toda suma dependiente o con varianza infinita sigue este TCL?

4. **Un paso más.** Si n se multiplica por 4, ¿por qué factor se divide el error estándar?

Hay pistas, comprobación y reintentos. Después de acertar, explica qué cambió y qué se mantuvo. Los controles tienen etiquetas y admiten teclado; las vistas 3D admiten giro con ratón, tacto o flechas. Versión iid con media finita y 0<σ²<∞. Dependencia o colas de varianza infinita pueden invalidarla; una variable Cauchy no cumple estas hipótesis.
