# Teorema central del límite

Las sumas estandarizadas de variables independientes de igual distribución y varianza finita tienden a una normal. El tamaño necesario para una buena aproximación depende de la distribución, no de una regla universal de treinta datos.

## Magnitudes

| Símbolo | Significado |
| :-- | :-- |
| Z | Suma centrada y estandarizada. |
| X | Variable aleatoria de un ensayo; barra: promedio de los n ensayos. |
| n | Número de variables independientes de igual distribución. |
| i | Índice de ensayo. |
| μ | Media común finita de cada variable. |
| σ | Desviación común positiva y finita. |
| N | Familia normal; N(0,1) tiene media cero y varianza uno. |
| d | Convergencia en distribución, no convergencia de cada resultado individual. |
| Var | Varianza de la variable entre paréntesis. |

## Alcance

Versión iid con media finita y 0<σ²<∞. Dependencia o colas de varianza infinita pueden invalidarla; una variable Cauchy no cumple estas hipótesis.

## Unidades

La media tiene la unidad de X; σ/√n también. Z es adimensional. Para Bernoulli, p y media no tienen dimensión, y la suma cuenta éxitos. Las barras estandarizadas tienen ancho 1/σ_suma y altura probabilidad dividida por ancho, para que su área sea la probabilidad exacta.
