# Tensor de Einstein

Tensor de Einstein en una base ortonormal de FLRW plano, con fluido p=wρc² y Λ=0. Tiempo, densidad y presión cambian sus componentes coherentemente.

## Magnitudes y notación

| Símbolo | Interpretación |
| :-- | :-- |
| G | Constante de gravitación de Newton; G con índices es el tensor de Einstein. |
| g | Tensor métrico que define intervalos y firma −+++. |
| μ | Índice de coordenada de espacio-tiempo, de cero a tres. |
| ν | Segundo índice tensorial de espacio-tiempo. |
| R | Curvatura escalar; R con índices es tensor de Ricci. |
| T | Tensor de energía-momento con índices; t minúscula es tiempo. |
| κ | Acoplamiento gravitatorio 8πG/c⁴. |
| Λ | Constante cosmológica, unidad m⁻². |
| c | Velocidad de la luz en vacío, 299 792 458 m/s. |
| H | Parámetro de Hubble, H=ȧ/a. |
| a | Factor de escala adimensional de una solución homogénea. |
| ρ | Densidad equivalente de masa, energía volumétrica dividida entre c². |
| p | Presión del fluido. |
| w | Razón adimensional p/(ρc²). |
| t | Tiempo cósmico propio de observadores comóviles. |
| ∇ | Derivada covariante compatible con la métrica. |
| i | Índice de componente espacial, de uno a tres. |
| ı | Índice de componente espacial en base ortonormal. |

## Condiciones

Convención de curvatura coherente con la ecuación escrita y firma −+++. Las componentes mostradas son covariantes en una base ortonormal, no componentes mixtas ni coordenadas comóviles sin factores de a. Λ=0 para este laboratorio; un fluido w=−1 es su fuente de vacío equivalente.

## Unidades

Tensor de Einstein y R en m⁻²; salida en 10⁻⁵² m⁻². ρ equivale a masa por volumen y p=wρc² está en Pa. El tiempo físico está en Gyr y H en s⁻¹ durante cálculo.
