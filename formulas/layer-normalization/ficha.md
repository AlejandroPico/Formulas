# Ficha

**Nombre:** Layer Normalization: normalización por capa

**Área:** Deep Learning

**Nivel:** Universidad intermedia

**Resumen:** Normaliza características dentro de una misma muestra, independiente del tamaño de batch.

## Lectura e interpretación

# Interpretación

Usa el simulador para ver qué variable domina: rareza corpus, entropía, dependencia, divergencia, outliers o estadística de normalización.

## Validez y limitaciones

# Limitaciones

No sustituye regularización; puede cambiar dinámica de escala y requiere ubicación arquitectónica adecuada.
