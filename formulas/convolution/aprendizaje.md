# Aprendizaje

## Primero predice

La convolución acumula cuánto se solapan una señal y otra invertida y desplazada. Describe la salida de un sistema lineal invariante en el tiempo ante una entrada.

Dos pulsos causales rectangulares se convolucionan. El segundo aparece invertido y desplazado: g(t−τ). El área de producto es la longitud del solape por A·B.

## Tres formas de aprender

**Solapamientos · Explorar · Señal resultante**

Entender filtros, respuestas de sistemas y acumulación temporal. El laboratorio permite señales de amplitud negativa y muestra área firmada; el sombreado identifica el solape, no otra señal medida.

## Cuatro misiones

1. **Predice el resultado.** Dos pulsos unitarios de duración 2 s. En t=1 s, ¿cuánto vale la convolución?

2. **Diseña una solución.** Desliza los pulsos hasta conseguir el máximo solape de 2 s.

3. **Piensa antes de cambiar.** ¿La convolución continua contiene una integral?

4. **Un paso más.** Para A=2, B=3 y solape=2 s, calcula el resultado.

Hay pistas, comprobación y reintentos. Después de acertar, explica qué cambió y qué se mantuvo. Los controles tienen etiquetas y admiten teclado; las vistas 3D admiten giro con ratón, tacto o flechas. Integral o suma convergente. Para interpretación como respuesta de un sistema se requiere linealidad e invariancia temporal; causalidad restringe soportes, pero no es parte de toda convolución abstracta.
