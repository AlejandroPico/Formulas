# Calor específico: modelo cuántico de Einstein

Un mol de átomos con tres osciladores por átomo y una frecuencia única. A baja T cuesta excitar niveles; a alta T Cv tiende a 3R.

## Magnitudes y notación

| Símbolo | Interpretación |
| :-- | :-- |
| C | Capacidad calorífica molar; CV a volumen constante. |
| V | Índice V: volumen constante. |
| R | Constante molar de los gases, 8,314462618 J/(mol·K). |
| x | Razón de temperatura de Einstein y temperatura absoluta. |
| θ | Temperatura característica de Einstein θE. |
| E | Índice E: Einstein en θE, no energía. |
| T | Temperatura absoluta del sólido. |
| ℏ | Constante de Planck reducida. |
| ω | Frecuencia angular común de los osciladores. |
| k | Constante de Boltzmann kB. |
| B | Índice B: Boltzmann. |
| U | Energía térmica molar sobre la energía de punto cero. |
| th | Índice th: parte térmica de la energía. |
| e | Número de Euler: base de exponenciales. |

## Condiciones

Sólido armónico ideal con una frecuencia común y θE constante. Captura congelación cuántica y límite clásico, pero no la ley T³ de baja temperatura que requiere un espectro de Debye. CV aquí es molar por mol de átomos, no calor específico por kilogramo.

## Unidades

T,θE K; x adimensional; R J/(mol·K); Uth J/mol; CV J/(mol·K). No debe sustituirse Celsius en θE/T.
